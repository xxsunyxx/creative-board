# M3 画布便签

> 目标：把画布从「列表」推进到「可打开、可操作」。

## 已完成

- `/canvases/[id]` 画布详情页。
- 从数据库读取便签，渲染到 React Flow。
- 拖动便签后保存位置（`x` / `y`）。
- 便签权重 1-9：
  - 内联数字输入；
  - 失焦 / Enter 保存；
  - 权重越高，边框越粗。
- 便签颜色：
  - 点击颜色圆点打开调色板；
  - 选择后保存。
- 便签备注：
  - 内联编辑 + 保存；
  - 每次保存追加一条 `inspiration_notes`；
  - 如果备注未变化，不重复追加；
  - 备注数显示在便签上；
  - 灵感库卡片里可展开「备注（同步自画布）」。
- 删除便签：
  - 二次确认；
  - 软删除节点；
  - 删除相关连接；
  - 灵感库条目保留。
- 画布列表：
  - 节点数排除已删除节点；
  - 卡片可打开画布。
- M3 冒烟测试：`pnpm check:m3`。
