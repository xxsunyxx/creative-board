## P1 结果节点闭环（M5b）

目标：结果节点从「一段正文」升级为「问题 → 论证 → 文档」。

- [x] P1.1 结果面板骨架：结果节点可打开输出面板，显示当前结果、状态和文档入口。
- [ ] P1.2 候选问题：根据入线图生成 3-5 个候选问题，存 `generation_history`，可选用一个。
- [ ] P1.3 结果生成：选中问题后生成结果预览，保留原结果，可重新生成。
- [ ] P1.4 保存文档：结果预览可编辑，保存到文档区；一个结果节点可保存多篇。
- [ ] P1.5 文档区体验：Markdown 展示、来源回链、空状态和错误状态。
- [ ] P1.6 结果节点面板的测试：问题、结果、保存、回链。

验收：

- 从一个结果节点出发，可以完成「生成问题 → 选问题 → 生成结果 → 保存文档」。
- 生成结果不会自动写入灵感库。
- 失败时保留旧结果，不覆盖。
