# 用户流程（草案 v0.2）

> 按「连接线 + 线上的维度框」和「灵感 / 输出两类节点」更新。
> 不是最终交互稿。

## 0. 全局导航（建议）

左侧边栏三个入口：

- 灵感库
- 画布（列表）
- 文档

主区域显示当前空间。画布和文档可以互相跳转。

## 1. 收集灵感

1. 打开灵感库。
2. 新增灵感：拖入文字 / 链接、粘贴 URL、手动输入。
3. AI 生成关键词；用户可以删除、补充、重新生成。
4. 灵感以卡片 / 列表呈现，显示标题、摘要、关键词、来源。
5. 待定：搜索、筛选、批量操作。

## 2. 融合灵感

1. 把灵感 A 拖到灵感 B 上。
2. AI 判断相关性：
   - 相关：生成融合后的新灵感 C（保留双方要点，去重 / 补充）。
   - 不相关：做文字整理（具体行为待定）。
3. 用户确认 / 编辑 C。
4. C 进入灵感库，标记来源 A、B。
5. 原文是否保留：待定；建议保留并标记「已融合」。

## 3. 发送到画布

1. 灵感卡片上点「发送到画布」。
2. 选择目标画布（已有或新建）。
3. 生成一份副本，成为画布上的灵感节点。
4. 画布与灵感库不同步；画布上可以自由修改。便签备注是例外，会自动追加回灵感文字。

### 便签编辑

- **权重**：1-9 的数字输入，表示重要性，参与 AI 排序。
- **颜色**：更换便签颜色，作为分组标记。
- **备注**：写独立备注，自动追加到灵感文字里；修改时更新同一条备注（待确认）。
- **删除**：只删除画布便签及其连线，灵感库条目保留。

## 4. 建立连接（核心）

1. 从节点 A 拉一条线到节点 B（灵感节点或输出节点）。
2. 连好后，线上出现关系类型选择器；用户选择第一个关系类型（约束 / 因果 / 类比……）。
3. 选好后，线上出现对应维度框，里面是 AI 生成的主维度。
4. 点击主维度，显示它的细节维度；选定一个。
5. 线上仍然有按钮：
   - **框外增加主维度框**：在同一条线上再加一个维度框（可以是新的关系类型）。
   - **框内增加细节维度**：在当前框里继续加子级。
6. 一条线可以有多个维度框，例如「约束」「因果」「类比」同时挂在 A-B 上。
7. 从 B 继续拉线到 C，形成跨灵感多跳。
8. 一个节点可以连多个目标（分支），多个来源可以汇到同一个节点（合并）。
9. 维度框只是线上的注释，不参与图的连通性。

### 画布显示（建议）

- 维度框默认折叠成线上的 chip，只显示关系类型和当前选择。
- 点击 chip 展开维度树；多个 chip 沿线上排列。
- 选中一条链时，高亮路径，其他内容变淡。
- 灵感节点和输出节点使用不同的视觉样式。

## 5. 生成输出

1. 选中一条链或一组相关连接。
2. 点「生成输出」。
3. 画布上出现输出节点，和选中的内容用一条**虚线**关联。
4. 输出节点显示候选问题；选择或编辑问题。
5. 生成结果预览；可编辑、重新生成。
6. 点「保存到文档」。
7. 文档区出现对应文档；输出节点保留，作为入口。
8. 一个输出节点可以保存多篇文档；输出节点也可以继续连接到其他灵感 / 输出。

## 6. 文档与回流

1. 打开文档区，查看 / 编辑文档。
2. 从文档跳回画布上的输出节点和连接。
3. 可以继续扩展画布，生成新版本（待定）。

## 7. 一个完整例子

灵感库里：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

操作：

1. 把 A 发送到「组织创新」画布，成为灵感节点。
2. 从 A 拉线到 B。
3. 线上出现「约束」按钮；点击，AI 生成主维度：成本、资源、法规、伦理、场景、能力。
4. 选「成本」，显示细节：人力成本、时间成本、沟通成本……
5. 选「沟通成本」，这条线现在带上「约束 · 成本 · 沟通成本」。
6. 线上继续点「＋主维度框」，添加「条件」框；选「在什么条件下促进 / 抑制」。
7. 选中 A → B 这条链，点「生成输出」。
8. 画布上出现输出节点，给出候选问题；选一个，生成结果预览。
9. 保存到文档区；输出节点保留。

## 待确认

- 关系类型选择器里放哪些类型，固定列表还是 AI 推荐。
- 一条线上的多个维度框如何排列，避免遮挡。
- 输出节点连接到其他节点时，是否也走「关系类型 → 主维度 → 细节」。
- 一个输出节点保存多篇文档时，是独立生成，还是同一结果的多版本。
- 结果预览能编辑、重新生成、部分采纳吗。
- 维度框能否手动编辑主维度 / 细节。
