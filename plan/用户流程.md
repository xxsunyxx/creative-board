# 用户流程（草案 v0.1）

> 把已确认的机制串成一条可走通的路径。不是最终交互稿。

## 0. 全局导航（建议）

左侧边栏三个入口：

- 灵感库
- 画布（列表）
- 文档

主区域显示当前空间。画布和文档可以互相跳转。

## 1. 收集灵感

1. 打开灵感库。
2. 新增灵感：拖入文字 / 链接、粘贴 URL、手动输入。
3. AI 生成关键词；用户可以删除、补充、重新生成。
4. 灵感以卡片 / 列表呈现，显示标题、摘要、关键词、来源。
5. 待定：搜索、筛选、批量操作。

## 2. 融合灵感

1. 把灵感 A 拖到灵感 B 上。
2. AI 判断相关性：
   - 相关：生成融合后的新灵感 C（保留双方要点，去重 / 补充）。
   - 不相关：做文字整理（具体行为待定）。
3. 用户确认 / 编辑 C。
4. C 进入灵感库，标记来源 A、B。
5. 原文是否保留：待定；建议保留并标记「已融合」。

## 3. 发送到画布

1. 灵感卡片上点「发送到画布」。
2. 选择目标画布（已有或新建）。
3. 生成一份副本，成为画布上的便利贴。
4. 画布与灵感库不同步；画布上可以自由修改。

## 4. 建立连接（核心）

1. 点击便利贴 A 的连接区。
2. AI 生成侧面候选（如：沟通成本、协作频率、信任）。
3. 刷新 / 回溯候选；选一个 → 生成侧面框。
4. 点击侧面框的连接区，AI 生成关系候选（条件、因果、转化……）。
5. 选一个 → 生成关系框。
6. 把关系框拖到便利贴 B，完成一段连接。
7. 从 B 继续连接，形成跨灵感多跳。
8. 一个灵感可以连多个目标（分支），多个来源可以汇到同一个灵感（合并）。
9. 框内可以加子级；只有最外层框能向外连。

### 画布显示（建议）

- 框默认折叠，只显示标题和子级数量。
- 展开后显示子级；展开状态不影响图连接。
- 选中一条链时，高亮路径，其他内容变淡。
- 分支 / 合并没有特殊节点，靠灵感节点的多条边表达。

## 5. 生成输出

1. 选中一条链或一组相关连接（框选 / 多选）。
2. 点「生成输出」。
3. 画布上出现输出框，和选中的内容关联。
4. 输出框显示候选问题；选择或编辑问题。
5. 生成预览；可编辑、重新生成。
6. 点「保存到文档」。
7. 文档区出现对应文档；输出框保留，作为入口。

## 6. 文档与回流

1. 打开文档区，查看 / 编辑文档。
2. 从文档跳回画布上的输出框和连接。
3. 可以继续扩展画布，生成新版本（待定）。

## 7. 一个完整例子

灵感库里：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

操作：

1. 把 A 发送到「组织创新」画布，成为便利贴。
2. 点击 A 的连接区，选「沟通成本」→ 生成侧面框。
3. 点击侧面框的连接区，选「条件关系」→ 生成关系框。
4. 把关系框连到 B。
5. 从 B 继续连接 C，形成多跳。
6. 选中 A → 侧面 → 关系 → B 这条链，点「生成输出」。
7. 输出框给出候选问题；选一个，生成预览。
8. 保存到文档区。

- 输出框如何选上下文：整条链、选中的一段，还是整个画布。
