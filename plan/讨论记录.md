### 当前理解

「创意画板」可能落在两个极端之间：

- 偏「画」：以笔刷、图形、图层为核心的创作工具；
- 偏「板」：以收集、摆放、关联想法和素材为核心的信息 / 灵感空间。

这两个方向的技术栈、交互方式和首版范围差别很大，先不做假设。

### 候选形态（仅用于讨论，不是提案）

| 形态 | 核心体验 | 首版可以很小 | 主要风险 |
| --- | --- | --- | --- |
| 灵感墙 / Moodboard | 把图片、文字、色卡、链接摆到无限画布上，靠空间关系激发联想 | 拖拽上传、卡片、缩放平移、只读分享链接 | 容易变成「另一个白板 / Figma」，需要想清楚差异 |
| 自由绘画 | 笔刷、图层、压感，强调手感与输出 | 单画布 + 几种笔刷 + 导出 PNG | 对性能和手感要求高，竞品成熟 |
| 想法地图 | 节点 + 连线，整理概念、做头脑风暴 | 节点、连线、折叠、导出 | 交互容易变复杂，价值取决于是否真有整理需求 |
| AI 共创画板 | 用文字或草图生成素材、变体、版式 | 一个生成入口 + 画布摆放 | 依赖模型能力与成本，容易做成 API 套壳 |
| 拼贴 / 海报工坊 | 模板 + 素材 + 排版，产出可发布的成品 | 少量模板 + 文字图片 + 导出 | 素材版权、模板设计工作量 |
