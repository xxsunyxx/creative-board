# 画布交互（草案 v0.1）

> 把已确认的规则落成可见的布局和操作。不是视觉稿，先对齐结构。

## 1. 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│ 灵感库 │ 画布：组织创新 ▾ │ 文档        [颜色图例] [搜索]  │
├──────┬───────────────────────────────────────────────────────┤
│ 灵感 │                                                       │
│ 列表 │     [便签 A] ──[约束 · 成本]──●──[便签 B]            │
│      │          │                      ┄┄┄                  │
│      │          └──[因果]──●──[便签 C]   [输出节点]          │
│      │                                                       │
└──────┴───────────────────────────────────────────────────────┘
```

- **左侧边栏**：灵感库、画布列表、文档。
- **顶部**：当前画布名、颜色图例、搜索、缩放。
- **主区域**：无限画布。
- **右侧可折叠面板**（可选）：选中节点 / 连线时显示详情。

## 2. 灵感便签

```
┌─────────────────────────┐
│ ● 3   标题          ⋯   │  ← 颜色、权重、菜单
│ 正文摘要……               │
│ #关键词  #关键词         │
│ 备注 2                  │
│                    ○    │  ← 连接点
└─────────────────────────┘
```

- **权重 1-9**：左上角数字徽章；边框粗细 / 颜色深浅随权重变化，便签尺寸不变。
- **颜色**：顶部色条或背景色；颜色对应一个 AI 自动生成的分组标签。
- **备注**：显示备注数量；点开右侧面板编辑；每次保存追加一段历史。
- **删除**：菜单或垃圾桶图标；只删除便签和连线，灵感库条目保留。
- **连接点**：从节点边缘拖出连线。

## 3. 连接线

1. 从节点 A 的连接点拖到节点 B。
2. 松手后弹出**关系类型选择器**：
   - 上半部分：AI 推荐的 3-5 个类型；
   - 下半部分：固定清单，可搜索。
3. 选中后，线上出现第一个维度框。
4. 连线中点保留 `＋` 按钮，用于添加更多维度框。

## 4. 维度框

### 折叠态

```
[便签 A] ──[约束 · 成本 · 人力成本]──●──[便签 B]
```

- 线上显示一个 chip：关系类型 + 当前选中的主维度 / 细节。
- 多个维度框时，chip 沿连线中点垂直堆叠；超过 3 个折叠成 `+N`。
- 点击 chip 展开。

### 展开态

```
┌─ 约束 ────────────────────┐
│ 主维度                     │
│  ├ 成本                  ▸ │
│  │   ├ 人力成本           │
│  │   └ 时间成本           │
│  ├ 资源                  ▸ │
│  └ 法规                  ▸ │
│                            │
│ ＋ 添加主维度   ＋ 添加细节 │
│ [刷新] [回溯] [手动编辑]   │
└────────────────────────────┘
```

- 点主维度展开细节；选一个细节后，chip 显示完整路径。
- `＋ 添加主维度`：在同一个维度框里加一个主维度。
- `＋ 添加细节`：在当前主维度下加子级。
- `＋ 框外增加主维度框`：在同一条线上再加一个维度框（新的关系类型）。
- 主维度 / 细节维度都可以手动增删改。

## 5. 输出节点

```
┌─ 输出 ─────────────────────┐
│ 问题：远程办公的沟通成本     │
│ 如何影响团队创新？           │
│                            │
│ 结果预览……                  │
│                            │
│ [重新生成] [保存到文档]      │
│ 文档 2 篇                  │
└────────────────────────────┘
        ┄┄┄ 虚线来源
```

- 输出节点使用不同形状 / 边框，和灵感便签区分。
- 与它总结的灵感组之间画一条虚线。
- 可以继续连接到其他灵感 / 输出，连接时同样走关系类型和维度框。
- 保存后可以继续生成新文档，文档彼此独立。

## 6. 颜色图例

- 顶部显示颜色 + AI 自动标签。
- 标签可编辑。
- 点击颜色可以高亮同组便签（可选）。
- 颜色标签什么时候生成：待确认。

## 7. 选择与批量操作

- 单击节点 / 连线：选中。
- Shift + 单击：多选。
- 框选：选择一组节点和连线。
- 选中后工具栏出现：生成输出、删除、对齐（可选）。

## 8. 关键交互

| 操作 | 结果 |
| --- | --- |
| 从连接点拖到另一个节点 | 创建连接线，弹出关系类型选择器 |
| 选择关系类型 | 线上出现第一个维度框 |
| 点维度框 chip | 展开主维度 / 细节树 |
| 点「＋ 框外增加主维度框」 | 同一条线增加第二个维度框 |
| 点「＋ 添加细节」 | 当前维度框内增加子级 |
| 修改权重 | 边框 / 角标变化，参与 AI 排序 |
| 换颜色 | 颜色变化，AI 更新分组标签 |
| 写备注并保存 | 追加一段备注到灵感文字 |
| 点删除 | 删除便签和连线，保留灵感库条目 |
| 选中一组节点 / 连线 → 生成输出 | 画布上出现输出节点，虚线关联来源 |
| 保存输出 | 文档区新增一篇独立文档 |
