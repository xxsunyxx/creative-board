# 画布交互（草案 v0.1）

> 把已确认的规则落成可见的布局和操作。不是视觉稿，先对齐结构。

## 1. 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│ 灵感库 │ 画布：组织创新 ▾ │ 文档        [颜色图例] [搜索]  │
├──────┬───────────────────────────────────────────────────────┤
│ 灵感 │                                                       │
│ 列表 │     [便签 A] ──[约束 · 成本]──●──[便签 B]            │
│      │          │                      ┄┄┄                  │
│      │          └──[因果]──●──[便签 C]   [输出节点]          │
│      │                                                       │
└──────┴───────────────────────────────────────────────────────┘
```

- **左侧边栏**：灵感库、画布列表、文档；可折叠成图标。
- **顶部**：当前画布名、颜色图例、搜索、缩放。
- **主区域**：无限画布。
- **右侧可折叠面板**（可选）：选中节点 / 连线时显示详情。

### 全屏 / 专注模式

- 画布详情页**默认全屏**：隐藏侧栏和页面留白，画布铺满视口。
- 保留浮动的返回 / 退出全屏按钮；退出后恢复侧栏和页面留白。
- 侧栏折叠后只显示图标；展开后恢复文字和说明。
- M6 在画布顶部显示 AI 消耗：**本次** / **本画布合计**（tokens + 费用）。

## 2. 灵感便签

```
┌─────────────────────────────┐
│ 3  ●  标题             🗑   │  ← 权重输入、颜色、删除
│ 正文摘要……                   │
│ #关键词  #关键词             │
│ 📝 备注 2                    │  ← 备注图标，点开写 / 看历史
│                        ○    │  ← 连接点
└─────────────────────────────┘
```

- **权重 1-9**：便签上的数字输入框，直接改；边框粗细 / 颜色深浅随权重变化，尺寸不变。
- **颜色**：便签上的颜色控件，点击换色；颜色对应一个 AI 自动生成的分组标签。
- **备注**：小图标 + 备注数量；点开在便签上展开备注输入和历史。
- **删除**：垃圾桶图标；只删除便签和连线，灵感库条目保留。
- **尺寸**：右下角缩放手柄，宽 180-520、高 120-480，尺寸落库。
- **连接点**：便签四边都有随动连接点，任意一边都能拖出连线；节点移动时连接点跟随。
- 这些操作都在便签上完成，不依赖右侧面板。

## 3. 连接线

1. 从节点 A 的任意一个连接点拖到节点 B 的连接点。
2. 松手后弹出**关系类型选择器**：
   - 上半部分：AI 推荐的 3-5 个类型；
   - 下半部分：固定清单，可搜索。
3. 选中后，线上出现第一个维度框。
4. 连线中点保留 `＋` 按钮，用于添加更多维度框。
5. 连线使用渐变描边 + 底描边 + 柔光 + 箭头 + 流动虚线 / 粒子。
6. 已有连接的端点按两节点中心向量与矩形边界求交，自动落在朝向对方的边线上；移动 / 交换位置时端点会沿边缘滑动。

## 4. 维度框

### 折叠态

```
[便签 A] ──[约束 · 成本 · 人力成本]──●──[便签 B]
```

- 线上显示一个 chip：关系类型 + 当前选中的主维度 / 细节。
- 多个维度框沿连线**平铺**，像路线上的节点；每个框占一个位置。
- 连线可以弯曲 / 拉长以容纳多个框；密集时自动缩小或折叠。
- 点击 chip 展开。

### 展开态

```
┌─ 约束 ────────────────────┐
│ 主维度                     │
│  ├ 成本                  ▸ │
│  │   ├ 人力成本           │
│  │   └ 时间成本           │
│  ├ 资源                  ▸ │
│  └ 法规                  ▸ │
│                            │
│ ＋ 添加主维度   ＋ 添加细节 │
│ [刷新] [回溯] [手动编辑]   │
└────────────────────────────┘
```

- 点主维度展开细节；选一个细节后，chip 显示完整路径。
- `＋ 添加主维度`：在同一个维度框里加一个主维度。
- `＋ 添加细节`：在当前主维度下加子级。
- `＋ 框外增加主维度框`：在同一条线上再加一个维度框（新的关系类型）。
- 主维度 / 细节维度都可以手动增删改。

## 5. 输出节点

```
┌─ 输出 ─────────────────────┐
│ 问题：远程办公的沟通成本     │
│ 如何影响团队创新？           │
│                            │
│ 结果预览……                  │
│                            │
│ [重新生成] [保存到文档]      │
│ 文档 2 篇                  │
└────────────────────────────┘
        ┄┄┄ 虚线来源
```

- 输出节点使用不同形状 / 边框，和灵感便签区分。
- **结果预览在节点内展开**；节点可以拉伸、滚动，长文不挤爆画布。
- 与它总结的灵感组之间画一条虚线。
- 可以继续连接到其他灵感 / 输出，连接时同样走关系类型和维度框。
- 保存后可以继续生成新文档，文档彼此独立。

## 6. 颜色图例

- 顶部显示颜色 + AI 自动标签。
- 标签可编辑。
- 点击颜色可以高亮同组便签（可选）。
- 颜色标签什么时候生成：待确认。

## 6.5 自动排布与吸附

- 画布默认 20×20 网格吸附。
- 顶部「自动排布」按钮用 Dagre 做左→右分层布局。
- 没有连接时，自动排布退化为网格排列。
- 自动排布后自动 fitView。
- 手动拖动仍然可用；后续可加对齐辅助线。

## 7. 选择与批量操作

- 单击节点 / 连线：选中。
- Shift + 单击：多选。
- 框选：选择一组节点和连线。
- 选中后工具栏出现：生成输出、删除、对齐（可选）。

## 8. 关键交互

| 操作 | 结果 |
| --- | --- |
| 从连接点拖到另一个节点 | 创建连接线，弹出关系类型选择器 |
| 选择关系类型 | 线上出现第一个维度框 |
| 点维度框 chip | 展开主维度 / 细节树 |
| 点「＋ 框外增加主维度框」 | 同一条线增加第二个维度框 |
| 点「＋ 添加细节」 | 当前维度框内增加子级 |
| 修改权重 | 边框 / 角标变化，参与 AI 排序 |
| 换颜色 | 颜色变化，AI 更新分组标签 |
| 写备注并保存 | 追加一段备注到灵感文字 |
| 点删除 | 删除便签和连线，保留灵感库条目 |
| 选中一组节点 / 连线 → 生成输出 | 画布上出现输出节点，虚线关联来源 |
| 保存输出 | 文档区新增一篇独立文档 |

## 9. 待确认

- 权重的边框 / 角标具体样式。
- 颜色标签什么时候生成：换色时自动生成，还是手动触发。
- 备注历史如何展示：按时间分组、折叠，还是只显示最近几条。
- 多个维度框沿线平铺时，连线弯曲 / 避让的具体规则。
- 输出节点拉伸 / 滚动的尺寸上限。
- 全屏模式下侧栏是隐藏还是折叠成浮层。
- AI 消耗显示位置：画布顶部 / 侧栏底部 / 设置页。
