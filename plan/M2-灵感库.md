# M2 灵感库

> 目标：把灵感库从「能存」推进到「能整理、能进入画布」。

## 已完成

- 新增灵感时自动生成关键词（本地 mock）。
- 关键词手动添加、删除、补充生成。
- 两条 active 灵感融合：
  - 生成一条新的灵感条目；
  - 原文保留并标记「已融合」；
  - 关键词合并去重。
- 发送到画布：
  - 选择目标画布；
  - 复制成 `canvas_nodes` 里的灵感节点；
  - 自动分配初始位置和颜色；
  - 画布列表节点数 +1。
- `/api/health` 增加节点计数。
- mock AI 模块：`lib/ai/mock.ts`。
- M2 Playwright 冒烟测试：`pnpm check:m2`。

## 验收结果（2026-10-23）

- 新增「M2 测试 A / B」后自动生成关键词。
- 手动添加「测试关键词」成功，删除成功。
- 融合生成「M2 测试 A × M2 测试 B」，两条原文都显示「已融合」。
- 发送融合条目到「组织创新」画布，`nodes` 从 0 → 1。
- 画布列表显示 1 个节点。
- 控制台无报错。
- 测试数据清理后恢复 1 画布 / 4 灵感 / 1 文档 / 0 节点。

## 已知限制

- 关键词是简单分词 + 规则过滤，不是真实 AI；后续替换 `lib/ai/mock.ts`。
- 融合是文本拼接 + 固定「待整理」提示，不是语义融合。
- 发送到画布暂不防重复；同一灵感可以发送多次。
- 画布还不能打开编辑，M3 接入。
- 融合条目暂未直接存 `mergedFrom`；通过原文的 `mergedInto` 反查来源。

```bash
pnpm check:m2
```

需要 dev server 正在运行。
