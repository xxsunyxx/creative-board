# M5a 节点角色与推理

> 目标：把画布从「灵感 + 输出两类节点」改成「一种便签、四种角色」。

## 已完成

- 数据模型：
  - `canvas_nodes.type` 改为角色：inspiration / process / result / blank。
  - 新增 `role_locked`。
  - 迁移 `0001_fast_martin_li.sql` 已修正，`pnpm db:check` 可在空库上跑通。
- 统一便签：
  - 底部角色下拉：灵感 / 过程 / 结果 / 空白。
  - 角色可手动覆盖，改变后锁定。
  - 默认标题随角色变化。
- 插入栏：
  - 空便签 / 空灵感 / 空过程 / 空结果 + 「开始推理」。
  - 画布内实时显示「N 便签 · M 连接」。
- 开始推理：
  - 扫描画布上所有空便签，推断角色，各生成一个候选内容。
  - mock 根据入 / 出邻居和关系类型生成。
- 插入过程：
  - 在维度面板点「插入过程节点」，把 A→B 拆成 A→P→B。
  - 原维度框全部移到 A→P。
- 正文编辑：
  - 便签底部「编辑」或双击正文，保存落库。
- Lucky：
  - 关系选择器：随机关系 + 随机条件。
  - 维度面板：随机选当前维度树里的一个条件。
- AI 设置页：
  - OpenAI / Claude / DeepSeek。
  - Key 只存本机 `localStorage`。
  - `/api/ai/test` 临时测试，不落盘。
  - 测试通过后才能保存。

## 验收结果（2026-10-23）

- 插入 2 个空灵感 + 1 个空结果，自动排布。
- 两条连接分别选「因果」「条件」。
- 开始推理：3 个空便签全部生成内容。
- 插入过程：节点 3 → 4，边 2 → 3；原维度框移到 A→P。
- 再次推理：过程节点生成内容。
- 改角色：过程 → 结果，DB 同步。
- Lucky：维度选中数 0 → 1。
- 正文编辑：结果节点内容改为「M5 测试正文」，DB 同步。
- 控制台无报错。
- AI 设置页：provider 列表、localStorage 读取、清除均通过。

## 已知限制

- 推理内容仍是 mock，比较模板化。
- 角色只在「开始推理」时推断；连线时不会实时改角色。
- 插入过程时，维度框默认全部移到 A→P；P→B 需要重新加。
- 结果节点的候选问题 / 文档面板还没做（M5b）。
- Key 存在 localStorage，任何同源脚本都能读到；适合本机单用户。
