# 核心机制（讨论稿 v0.2）

> 基于 2026-10-23 用户描述整理，尚未定稿。
> 产品边界见 [产品定义](产品定义.md)。

## 信息架构（修正）

不再是固定三栏布局，而是三个独立空间：

| 空间 | 作用 | 入口 |
| --- | --- | --- |
| 灵感库 | 收集、融合、关键词；灵感条目的家 | 独立页面 / 侧边栏 |
| 画布 | 把灵感变成便利贴，建立连接，产生输出 | 可创建多个画布 |
| 文档 | 输出框生成的成稿 | 独立文档区 / 从输出框打开 |

- 灵感条目带「发送到画布」按钮，可选择目标画布。
- 画布可以有多个，按主题 / 项目组织（待确认）。
- 输出框在画布上，是流程中的显眼节点；生成文档后，形成对应文档。
- 文档与输出框保持对应关系（待确认是否双向链接）。

## 1. 灵感库

- 支持拖拽、链接、文字等方式收集。
- 每条内容成为一条灵感条目。
- 条目可生成关键词；关键词可删除、自动生成、手动增加。
- 两个条目可以拖到一起重新构造：
  - **相关**：融合、补充。
  - **不相关**：进行文字整理。
- **融合后生成一个新的灵感条目**，不是收敛结果。
- 新条目可以继续作为灵感使用：再次发送到画布、继续融合、继续生成。

### 待确认

- 融合后原文是否保留？是保留为来源 / 子项，还是删除？
- 「相关 / 不相关」由 AI 自动判断，还是用户先选？
- 「发送到画布」是复制一份，还是引用同一个灵感？画布上的修改会不会回写？
- 关键词除了标签，还有什么用途？搜索、连接提示、还是 AI 上下文？

## 2. 画布

- 灵感通过「发送到画布」变成便利贴。
- 便利贴周边有连接区。
- 点击连接区，AI 生成「连接途径 / 特质」。
- 特质可以刷新、回溯。
- 选定特质后生成「特质框」，把特质写入框内。
- 特质框连接到另一个灵感。
- 特质框可以多层级，例如：约束 → 成本 → 人力成本。
- 两个内容可以连接到第三个内容；**第三个是普通灵感，或 AI 生成的灵感**，不是特质框。
- 输出框在画布上，连接后出现；生成文档后形成对应文档。

### 连接流程

```
[便利贴 A] --点击连接区--> AI 生成候选特质
                                  ↓
                          选择 / 刷新 / 回溯
                                  ↓
                          {特质框：某方向的特质}
                                  ↓
                         连接到 [便利贴 B]
```

### 两个内容 → 第三个内容

```
[A] + [B] → [C]
```

- C 可以是普通灵感，也可以是 AI 生成的灵感。
- C 生成后是否自动进入灵感库？待确认。
- C 如果进入灵感库，就可以再次发送到画布，形成下一轮。

### 待确认

- 一个画布可以有多少个输出框？
- 输出框是每条连接一个，还是每组连接一个？
- 第三个灵感是用户手动创建、AI 生成，还是两者都可以？

## 3. 特质框（核心）

### 建议的统一模型

特质框不只装一个词，而是装四层信息：

```
[远程办公]
   │ 点击连接区
   ▼
{特质框
  侧面：沟通成本
  关系：条件关系（什么条件下促进/抑制）
  属性：强度、证据、时间尺度…}
   │
   ▼
[团队创新]
```

- **侧面**：这个灵感哪一面被拿来连接（成本、伦理、因果、类比……）。
- **关系**：这一面连到 B 时是什么关系（条件、因果、转化……）。
- **属性**：方向、强度、确定性、时间尺度等。
- **子级**：侧面可以展开（约束 → 成本 → 人力成本），关系也可以展开。

> 这个统一模型还没有得到用户确认，是先前的建议。

### 关系词汇表（用户提供，待整理）

| 维度 | 取值 / 说明 |
| --- | --- |
| 关系类型 | 因果（A→B / B→A / 共同导致 C）、相关（同涨同落，未必因果）、类比（A 像 B，可迁移机制）、组合（A+B → 新功能/产品/场景）、对立/张力（冲突、制衡、替代）、条件（在什么条件下 A 促进/抑制 B）、转化（A 的某属性 → B 的某价值）、尺度映射（个体→组织/社会；A→B、B→A、双向互构、第三因素驱动） |
| 机制层级 | 现象层、结构层、动力层、语义层、价值层 |
| 推理距离/新颖度 | 同域近迁移、跨域远迁移、反常识断裂 |
| 确定性/证据强度 | 事实必然、概率较高、合理假设、隐喻启发、纯猜想 |
| 时间尺度 | 即时、短期、长期、演化性 |
| 作用强度 | 弱关联、强因果、瓶颈、放大器、触发器 |
| 主体视角 | 用户、组织、技术、市场、社会、生态 |
| 约束条件 | 成本、资源、法规、伦理、场景、能力 |
| 输出用途 | 解释、预测、设计、批判、决策、叙事 |
| 可验证性 | 可量化、可原型、可观察、暂不可验证 |
| 价值/风险 | 高价值低风险、高价值高风险、低价值高风险等 |

> 注意：这份清单混合了「关系类型」「关系属性」「分析视角」三类东西。统一模型可以把它们分别放进侧面、关系、属性里。

## 4. 输出框与文档

- 输出框放在**画布上**，是流程中显眼的节点，不是侧边栏。
- 连接后出现输出框，内含 AI 生成的候选问题。
- 选择一个（或多个）问题后，AI 生成结果。
- 生成文档后，形成一个**对应的文档**。
- 输出框作为流程依据保留在画布上，可以点开对应文档。

### 待确认

- 输出框是每条连接一个、每组连接一个，还是整个画布一个？
- 候选问题是针对这条关系、这组便利贴，还是整个主题？
- 文档是什么形态：一段结论、一篇结构化笔记，还是可继续编辑的长文？
- 一个输出框能生成多篇文档吗？文档能反向链接回输出框吗？
- 生成的文档放在哪里？独立文档区、画布侧边，还是新页面？

## 5. 一个完整例子（待用户确认）

灵感库里：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

操作：

1. A 和 B 可以融合成新条目 C；C 继续留在灵感库。
2. 把 A 发送到「组织创新」画布，成为便利贴。
3. 点击 A 的连接区，AI 生成候选特质：沟通成本、协作频率、信任、工具能力……
4. 选择「沟通成本」，生成特质框。
5. 把特质框连到 B。
6. 画布上出现输出框，给出候选问题：
   - 远程办公的沟通成本如何影响团队创新？
   - 什么条件下远程办公会抑制而不是促进创新？
   - 哪些工具或机制可以抵消这种影响？
7. 选择一个问题，AI 生成文档。
8. 画布上保留输出框，并形成一个对应文档。

## 6. 当前理解

- 产品不是固定三栏，而是「灵感库 + 多个画布 + 文档」。
- 灵感库是源头，融合产物仍回到灵感库，可以继续生成。
- 画布是关系发生的地方；特质框是核心表达单位。
- 输出框是画布上的流程节点，文档是它的产物。
- 最终价值不在画布好看，而在能否把灵感推进成一篇想清楚的文档。
