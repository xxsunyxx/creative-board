# 核心机制（讨论稿 v0.4）

> 基于 2026-10-23 用户描述整理，尚未定稿。
> 本版把连接模型改为「连接线 + 线上的维度框」，并把结果 / 输出 / 文档分开。
> 产品边界见 [产品定义](产品定义.md)。

## 信息架构

| 空间 | 作用 | 入口 |
| --- | --- | --- |
| 灵感库 | 收集、融合、关键词；灵感条目的家 | 独立页面 / 侧边栏 |
| 画布 | 灵感节点、输出节点、连接线与维度框 | 可创建多个画布 |
| 文档 | 输出节点保存后的成稿 | 独立文档区 |

- 灵感条目带「发送到画布」按钮，可选择目标画布。
- 灵感发送到画布时：**直接复制一份**，画布和灵感库之间不同步。
- 画布可以有多个，按主题 / 项目组织（待确认）。

## 1. 灵感库

- 支持拖拽、链接、文字等方式收集。
- 每条内容成为一条灵感条目。
- 条目可生成关键词；关键词可删除、自动生成、手动增加。
- 两个条目可以拖到一起重新构造：
  - **相关**：融合、补充。
  - **不相关**：进行文字整理。
- **融合后生成一个新的灵感条目**，不是收敛结果。
- 新条目可以继续作为灵感使用：再次发送到画布、继续融合、继续生成。

### 待确认

- 融合后原文是否保留？是保留为来源 / 子项，还是删除？
- 「相关 / 不相关」由 AI 自动判断，还是用户先选？
- 关键词除了标签，还有什么用途？搜索、连接提示、还是 AI 上下文？

## 2. 画布

画布上有两类节点：

- **灵感节点**：从灵感库复制来的便利贴。
- **输出节点**：承载结果和文档入口的节点。

连接线连接节点；**维度框挂在连接线上**，不是独立节点。

### 便签属性（已确认）

- **权重**：1-9 的数字输入，表示重要性；用于 AI 生成时的优先级排序。
- **颜色**：便签可以更换颜色，颜色作为**分组标记**。
- **备注**：便签可以写独立备注；备注**自动追加**到灵感文字里。
- **删除**：只删除画布便签及其连线，灵感库条目保留。

待确认：

- 自动追加的幂等性：备注修改后，是更新同一段，还是重复追加？
- 颜色分组是否需要名称 / 图例？
- 权重是否影响便签的视觉大小？

### 两个内容 → 第三个内容

```
[A] + [B] → [C]
```

- C 可以是普通灵感，也可以是 AI 生成的灵感。
- C 生成后是否自动进入灵感库？待确认。
- C 如果进入灵感库，就可以再次发送到画布，形成下一轮。

## 3. 连接线与维度框（核心）

### 基本流程

1. 点击节点 A 的连接点，连到节点 B。
2. 连好后，线上出现关系类型选择器；用户选择第一个关系类型（约束 / 因果 / 类比……）。
3. 选好后，线上出现对应的维度框，里面是 AI 生成的主维度。
4. 点击主维度，显示它的细节维度；选定一个。
5. 线上仍然有按钮：
   - **框外增加主维度框**：在同一条线上再加一个维度框（可以是新的关系类型）。
   - **框内增加细节维度**：在当前框里继续加子级。

### 图示

```
[灵感 A] ───────────●─────────── [灵感 B]
                    │
                 [约束]  ← 线上的关系类型按钮
                    │ 点击
                    ▼
            ┌─ 约束框 ─────────┐
            │ 主维度：成本      │
            │   ├ 人力成本      │
            │   └ 时间成本      │
            │ 主维度：资源      │
            │   └ ...           │
            └──────────────────┘
```

选定后：

```
[灵感 A] ──[约束 · 成本 · 人力成本]──●──[灵感 B]
                                      │
                             ＋主维度框 / ＋细节维度
```

### 规则

- **连接线是主对象**；先连线，再在线上加维度框。
- **连接的两端可以是灵感节点，也可以是输出节点**；输出节点可以继续连接，作为下一轮输入。
- **维度框是线上的注释**，不是图节点；不参与其他连接。
- 一条线可以有多个维度框，例如「约束」「因果」「类比」同时挂在 A-B 上。
- 每个维度框内部是一棵树：**关系类型 → 主维度 → 细节维度 → 更深细节**。
- 维度框可以刷新、回溯、编辑、删除（待确认）。
- 多层 = 多个维度框 + 框内细节树 + 跨灵感多跳。
- 分支 / 合并：节点可以有多条入线 / 出线。
- 维度框不改变图的连通性；它只描述这条线「从哪个方向连」。

### 关系类型（维度框的类别）

| 维度 | 取值 / 说明 |
| --- | --- |
| 关系类型 | 因果（A→B / B→A / 共同导致 C）、相关（同涨同落，未必因果）、类比（A 像 B，可迁移机制）、组合（A+B → 新功能/产品/场景）、对立/张力（冲突、制衡、替代）、条件（在什么条件下 A 促进/抑制 B）、转化（A 的某属性 → B 的某价值）、尺度映射（个体→组织/社会；A→B、B→A、双向互构、第三因素驱动）、约束（成本、资源、法规、伦理、场景、能力） |
| 机制层级 | 现象层、结构层、动力层、语义层、价值层 |
| 推理距离 / 新颖度 | 同域近迁移、跨域远迁移、反常识断裂 |
| 确定性 / 证据强度 | 事实必然、概率较高、合理假设、隐喻启发、纯猜想 |
| 时间尺度 | 即时、短期、长期、演化性 |
| 作用强度 | 弱关联、强因果、瓶颈、放大器、触发器 |
| 主体视角 | 用户、组织、技术、市场、社会、生态 |
| 输出用途 | 解释、预测、设计、批判、决策、叙事 |
| 可验证性 | 可量化、可原型、可观察、暂不可验证 |
| 价值 / 风险 | 高价值低风险、高价值高风险、低价值高风险等 |

> 关系类型既可以作为维度框的类别，也可以作为主维度 / 细节维度的属性。首版先做少量类型，避免一次铺满。

### 待确认

- 一条线上的多个维度框如何排列，避免遮挡？
- 维度框的刷新 / 回溯是保留历史，还是只保留当前选择？
- 维度框可以手动编辑主维度 / 细节，还是只能从 AI 候选里选？
- 是否允许只有连接线、没有任何维度框的「裸线」？

## 4. 输出节点、结果与文档

三层分开：

| 概念 | 含义 | 位置 |
| --- | --- | --- |
| 输出 | 画布上的输出节点，承载一次结论 | 画布 |
| 结果 | 输出节点里的 AI 生成内容（预览 / 最终） | 输出节点内 |
| 文档 | 保存后的成稿 | 文档区 |

- 输出节点是画布上的一等节点，**可以继续连接到其他灵感 / 输出**，作为下一轮的输入。
- 创建方式：选中一条链或一组连接 → 点「生成输出」→ 输出节点出现。
- 输出节点和它总结的灵感组之间画一条**虚线**，表示来源关系。
- 输出节点内包含：
  - AI 生成的候选问题；
  - 问题对应的结果预览；
  - 「保存到文档」按钮。
- 保存后，文档区出现对应文档；输出节点保留，作为入口。
- **一个输出节点可以保存多篇文档。**

### 待确认

- 输出节点连到灵感 / 输出时，是否也走「关系类型 → 主维度 → 细节」这一套？
- 一个输出节点保存多篇文档时，是一篇篇独立生成，还是同一结果的多版本？
- 结果预览可以编辑、重新生成、部分采纳吗？
- 输出节点是手动创建，还是连接满足条件后自动出现？

## 5. 一个完整例子

灵感库里：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

操作：

1. 把 A 发送到「组织创新」画布，成为灵感节点。
2. 从 A 拉一条线到 B。
3. 线上出现「约束」按钮；点击，AI 生成主维度：成本、资源、法规、伦理、场景、能力。
4. 选「成本」，显示细节：人力成本、时间成本、沟通成本……
5. 选「沟通成本」，这条线现在带上「约束 · 成本 · 沟通成本」。
6. 线上继续点「＋主维度框」，添加「条件」框；选「在什么条件下促进 / 抑制」。
7. 选中 A → B 这条链，点「生成输出」。
8. 画布上出现输出节点，给出候选问题：
   - 远程办公的沟通成本如何影响团队创新？
   - 什么条件下远程办公会抑制而不是促进创新？
9. 选一个问题，生成结果预览；确认后保存。
10. 文档区出现对应文档；输出节点保留在画布上，作为入口。

## 6. 当前理解

- 产品是「灵感库 + 多个画布 + 文档」。
- 画布上有两类节点：灵感、输出。
- 连接线是主对象；维度框是线上的注释，一条线可以有多个。
- 维度框内部是「关系类型 → 主维度 → 细节维度」的树。
- 多层 = 多个维度框 + 框内细节树 + 跨灵感多跳。
- 结果、输出、文档三层分开。
- 最终价值不在画布好看，而在能否把灵感推进成一篇想清楚的文档。
