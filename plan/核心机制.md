# 核心机制（讨论稿 v0.3）

> 基于 2026-10-23 用户描述整理，尚未定稿。
> 产品边界见 [产品定义](产品定义.md)。

## 信息架构

| 空间 | 作用 | 入口 |
| --- | --- | --- |
| 灵感库 | 收集、融合、关键词；灵感条目的家 | 独立页面 / 侧边栏 |
| 画布 | 把灵感变成便利贴，建立连接，产生输出 | 可创建多个画布 |
| 文档 | 输出框保存后的成稿 | 独立文档区 |

- 灵感条目带「发送到画布」按钮，可选择目标画布。
- 灵感发送到画布时：**直接复制一份**，画布和灵感库之间不同步。
- 画布可以有多个，按主题 / 项目组织（待确认）。
- 输出框在画布上，手动创建；保存后写入文档区。

## 1. 灵感库

- 支持拖拽、链接、文字等方式收集。
- 每条内容成为一条灵感条目。
- 条目可生成关键词；关键词可删除、自动生成、手动增加。
- 两个条目可以拖到一起重新构造：
  - **相关**：融合、补充。
  - **不相关**：进行文字整理。
- **融合后生成一个新的灵感条目**，不是收敛结果。
- 新条目可以继续作为灵感使用：再次发送到画布、继续融合、继续生成。

### 待确认

- 融合后原文是否保留？是保留为来源 / 子项，还是删除？
- 「相关 / 不相关」由 AI 自动判断，还是用户先选？
- 关键词除了标签，还有什么用途？搜索、连接提示、还是 AI 上下文？

## 2. 画布

- 灵感通过「发送到画布」变成便利贴。
- 便利贴周边有连接区。
- 点击连接区，AI 生成连接方向。
- 连接由**侧面框**和**关系框**两种节点组成，已确认分开，不用一个统一特质框。
- 两个内容可以连接到第三个内容；第三个是普通灵感，或 AI 生成的灵感。
- 输出框手动创建，放在画布上。

### 两个内容 → 第三个内容

```
[A] + [B] → [C]
```

- C 可以是普通灵感，也可以是 AI 生成的灵感。
- C 生成后是否自动进入灵感库？待确认。
- C 如果进入灵感库，就可以再次发送到画布，形成下一轮。

## 3. 侧面框与关系框（已确认分开）

### 建议的连接链（待确认）

```
[A 远程办公]
   │ 点击连接区
   ▼
{侧面框：沟通成本}
   │ 点击连接区
   ▼
{关系框：条件关系（什么条件下促进/抑制）}
   │
   ▼
[B 团队创新]
```

- **侧面框**：A 的某一面被拿来连接（成本、伦理、因果、类比……）。
- **关系框**：这一面连到 B 时是什么关系（条件、因果、转化……）。
- 两种框都可以有属性 / 子级。
- **已确认：连接必须支持多层，不能砍成一层。**
- 已确认的多层类型：
  1. **框内嵌套**：约束 → 成本 → 人力成本；因果 → 条件 → 阈值。
  2. **链式连接**：A → 侧面 → 关系 → 侧面 → 关系 → B。
  3. **跨灵感多跳**：A → 侧面 / 关系 → B → 侧面 / 关系 → C。
- 未选择：分层分组（一级关系 / 二级解释 / 三级证据）。
- **已确认的图结构规则**：
  - 链式连接允许分支和合并。
  - 一条链的两端都是灵感；输出框不作为链的端点。
  - 框内嵌套的子级不能向外连接，只有最外层框能连。
  - 数据层不限制层数 / 跳数；UI 默认折叠，按需展开。
- 仍未确认：
  - 一条完整链是否固定为「灵感 → 侧面 → 关系 → 灵感」，还是允许连续多个侧面 / 关系？
  - 是否保留「快速连接」：不选侧面 / 关系，直接连两个灵感？
  - 分支 / 合并在画布上如何显示，避免变成蜘蛛网？
  - 框内嵌套是只做同类嵌套，还是侧面和关系可以交叉嵌套？

### 关系词汇表（用户提供，待整理）

| 维度 | 取值 / 说明 |
| --- | --- |
| 关系类型 | 因果（A→B / B→A / 共同导致 C）、相关（同涨同落，未必因果）、类比（A 像 B，可迁移机制）、组合（A+B → 新功能/产品/场景）、对立/张力（冲突、制衡、替代）、条件（在什么条件下 A 促进/抑制 B）、转化（A 的某属性 → B 的某价值）、尺度映射（个体→组织/社会；A→B、B→A、双向互构、第三因素驱动） |
| 机制层级 | 现象层、结构层、动力层、语义层、价值层 |
| 推理距离/新颖度 | 同域近迁移、跨域远迁移、反常识断裂 |
| 确定性/证据强度 | 事实必然、概率较高、合理假设、隐喻启发、纯猜想 |
| 时间尺度 | 即时、短期、长期、演化性 |
| 作用强度 | 弱关联、强因果、瓶颈、放大器、触发器 |
| 主体视角 | 用户、组织、技术、市场、社会、生态 |
| 约束条件 | 成本、资源、法规、伦理、场景、能力 |
| 输出用途 | 解释、预测、设计、批判、决策、叙事 |
| 可验证性 | 可量化、可原型、可观察、暂不可验证 |
| 价值/风险 | 高价值低风险、高价值高风险、低价值高风险等 |

> 这份清单混合了「关系类型」「关系属性」「分析视角」三类东西。分成侧面框和关系框后，可以分别承载：
> - 侧面框：约束、视角、层级等；
> - 关系框：因果、相关、类比、条件等；
> - 属性：强度、证据、时间尺度等。

## 4. 输出框与文档（已修正）

- 输出框**手动创建**，不自动出现。
- 放在画布上，是流程中显眼的节点。
- 创建后，输出框内显示 AI 生成的候选问题。
- 选择问题 / 生成后，先显示**预览结果**。
- 确认后点击保存，写入**文档区**。
- 输出框保留在画布上，作为对应文档的入口。

## 5. 一个完整例子（待用户确认）

灵感库里：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

操作：

1. A 和 B 可以融合成新条目 C；C 继续留在灵感库。
2. 把 A 发送到「组织创新」画布，成为便利贴（复制一份）。
3. 点击 A 的连接区，AI 生成侧面候选：沟通成本、协作频率、信任、工具能力……
4. 选择「沟通成本」，生成侧面框。
5. 点击侧面框的连接区，AI 生成关系候选：条件关系、因果关系、转化关系……
6. 选择「条件关系」，生成关系框，连到 B。
7. 手动创建一个输出框，把它和这组连接关联起来。
8. 输出框给出候选问题：
   - 远程办公的沟通成本如何影响团队创新？
   - 什么条件下远程办公会抑制而不是促进创新？
   - 哪些工具或机制可以抵消这种影响？
9. 选择一个问题，生成预览结果；确认后保存，写入文档区。
10. 画布上保留输出框，作为对应文档的入口。

## 6. 当前理解

- 产品是「灵感库 + 多个画布 + 文档」，不是固定三栏。
- 灵感库是源头，融合产物仍回到灵感库，可以继续生成。
- 画布是关系发生的地方；侧面框和关系框是两种不同的节点。
- 输出框手动创建，是画布上的流程节点；先预览，再保存成文档。
- 最终价值不在画布好看，而在能否把灵感推进成一篇想清楚的文档。
