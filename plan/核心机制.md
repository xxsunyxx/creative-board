# 核心机制（讨论稿）

> 基于 2026-10-23 用户描述整理，尚未定稿。
> 这份文档负责把「怎么用」讲清楚；产品边界见 [产品定义](产品定义.md)。

## 三个区域

| 区域 | 作用 | 输入 | 输出 |
| --- | --- | --- | --- |
| 灵感 | 收集与初步融合 | 链接、文字、拖拽内容 | 一条条灵感条目、关键词 |
| 画布 | 空间化思考与连接 | 从灵感区送来的条目 | 便利贴、特质框、连接、输出框 |
| 收敛 | 沉淀结果 | 输出框生成的结果 | 结构化笔记 / 结论 |

## 1. 灵感区

- 支持拖拽、链接、文字等方式收集。
- 每条内容成为一条灵感条目。
- 条目可生成关键词；关键词可删除、自动生成、手动增加。
- 两个条目可以拖到一起重新构造：
  - **相关**：融合、补充。
  - **不相关**：进行文字整理。

### 待确认

- 融合后原文是否保留？是生成新条目，还是直接替换？
- 「相关 / 不相关」由 AI 自动判断，还是用户先选？
- 关键词除了标签，还有什么用途？搜索、连接提示、还是 AI 上下文？

## 2. 画布区

- 灵感条目发送到画布，成为便利贴。
- 便利贴周边有连接区。
- 点击连接区，AI 生成「连接途径 / 特质」。
- 特质可以刷新、回溯。
- 选定特质后生成「特质框」，把特质写入框内。
- 特质框连接到另一个灵感。
- 特质框可以多层级，例如：约束 → 成本 → 人力成本。
- 也支持两个内容连接到第三个内容。

### 连接流程（按用户描述）

```
[便利贴 A] --点击连接区--> AI 生成候选特质
                                  ↓
                          选择 / 刷新 / 回溯
                                  ↓
                          {特质框：某方向的特质}
                                  ↓
                         连接到 [便利贴 B]
```

### 核心歧义

特质框到底代表什么，目前有两种可能：

**A. 灵感 A 的侧面（facets）**

```
[远程办公] --{沟通成本}--> [团队创新]
```

含义：拿「远程办公的沟通成本」这个侧面，去连接「团队创新」。
多层级：约束 → 成本 → 人力成本。

**B. A 与 B 之间的关系（reified edge）**

```
[远程办公] --{条件关系：在什么条件下促进/抑制}--> [团队创新]
```

含义：特质框描述的是 A 和 B 之间的关系类型、方向和属性。
多层级：关系类型 → 子类型 → 证据 / 强度 / 时间尺度。

> 这两种模型会直接影响数据结构、AI 提示词和交互，需要先确认。

### 关系词汇表（用户提供，待整理）

| 维度 | 取值 / 说明 |
| --- | --- |
| 关系类型 | 因果（A→B / B→A / 共同导致 C）、相关（同涨同落，未必因果）、类比（A 像 B，可迁移机制）、组合（A+B → 新功能/产品/场景）、对立/张力（冲突、制衡、替代）、条件（在什么条件下 A 促进/抑制 B）、转化（A 的某属性 → B 的某价值）、尺度映射（个体→组织/社会；A→B、B→A、双向互构、第三因素驱动） |
| 机制层级 | 现象层、结构层、动力层、语义层、价值层 |
| 推理距离/新颖度 | 同域近迁移、跨域远迁移、反常识断裂 |
| 确定性/证据强度 | 事实必然、概率较高、合理假设、隐喻启发、纯猜想 |
| 时间尺度 | 即时、短期、长期、演化性 |
| 作用强度 | 弱关联、强因果、瓶颈、放大器、触发器 |
| 主体视角 | 用户、组织、技术、市场、社会、生态 |
| 约束条件 | 成本、资源、法规、伦理、场景、能力 |
| 输出用途 | 解释、预测、设计、批判、决策、叙事 |
| 可验证性 | 可量化、可原型、可观察、暂不可验证 |
| 价值/风险 | 高价值低风险、高价值高风险、低价值高风险等 |

> 注意：这份清单混合了「关系类型」「关系属性」「分析视角」三类东西。产品上可以都作为 AI 生成特质的提示词；技术实现时需要区分，否则数据模型会混乱。

## 3. 输出框与收敛区

- 对灵感进行连接后，出现输出框。
- 输出框内有 AI 生成的候选问题。
- 选择一个（或多个）问题后，AI 输出结果。
- 结果进入收敛区。

### 待确认

- 输出框是每条连接一个、每组连接一个，还是整个画布一个？
- 候选问题是针对这条关系、这组便利贴，还是整个主题？
- 结果是什么形态：一段结论、一个问题清单、还是一篇结构化笔记？
- 结果进入收敛区是自动的，还是用户确认后？

## 4. 一个完整例子（待用户确认）

假设灵感区有两条内容：

- A：远程办公降低通勤成本，但沟通变慢。
- B：团队创新需要高频碰撞。

发送到画布后：

1. 点击 A 的连接区，AI 生成候选特质：沟通成本、协作频率、信任、工具能力……
2. 选择「沟通成本」，生成特质框。
3. 把特质框连到 B。
4. 输出框给出候选问题，例如：
   - 远程办公的沟通成本如何影响团队创新？
   - 什么条件下远程办公会抑制而不是促进创新？
   - 哪些工具或机制可以抵消这种影响？
5. 选择一个好问题，AI 输出一段结论。
6. 结论进入收敛区，和 A、B 保持引用关系。

## 5. 当前理解

- 这不是普通白板，而是「带关系语义的思考画布」。
- 核心差异化不是便利贴，而是**连接前先让 AI 生成「从哪个方向连」**。
- 关系不是简单的一条线，而是可以展开、可以带属性的中间节点。
- 最终价值在收敛区：不是摆得好看，而是产出一个想清楚了的结果。
