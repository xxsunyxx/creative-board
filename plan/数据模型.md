# 概念数据模型（草案 v0.1）

> 只描述对象和关系，不涉及技术选型。
> 目标是把「灵感库 / 画布 / 文档」和「多层连接」说清楚。

## 对象

### Inspiration（灵感）

- `id`
- `title`
- `content`
- `sourceUrl`（可空）
- `keywords[]`
- `mergedFrom[]`（来源灵感 id）
- `status`：active / merged / archived
- `createdAt` / `updatedAt`

### Canvas（画布）

- `id`
- `name`
- `description`
- `createdAt` / `updatedAt`

### StickyNote（便利贴）

- `id`
- `canvasId`
- `sourceInspirationId`（仅用于溯源，不同步）
- `title`
- `content`
- `position`（x, y）
- `size`（可空）

### FacetBox（侧面框）

- `id`
- `canvasId`
- `parentId`（可空；用于框内嵌套）
- `label`
- `attributes`（可空，键值对）
- `depth`（0 = 最外层，参与图连接）
- `children[]`

### RelationBox（关系框）

- `id`
- `canvasId`
- `parentId`（可空；用于框内嵌套）
- `label`
- `relationType`（因果 / 条件 / 类比 / 转化……）
- `attributes`（方向、强度、证据、时间尺度……）
- `depth`（0 = 最外层，参与图连接）
- `children[]`

### Connection（连接边）

- `id`
- `canvasId`
- `fromNodeId`
- `toNodeId`
- `type`：
  - `inspiration → facet`
  - `facet → relation`
  - `relation → inspiration`
- 允许分支 / 合并：同一个节点可以有多条入边 / 出边。

### OutputBox（输出框）

- `id`
- `canvasId`
- `contextNodeIds[]`（这条输出引用的节点 / 路径）
- `questions[]`（AI 候选问题）
- `selectedQuestion`
- `preview`（预览结果）
- `status`：draft / saved
- `createdAt` / `updatedAt`

### Document（文档）

- `id`
- `outputBoxId`
- `title`
- `content`
- `createdAt` / `updatedAt`

### GenerationHistory（生成历史）

- `id`
- `nodeId`
- `kind`：facet / relation / question / preview
- `candidates[]`
- `selected`
- `createdAt`

## 图结构

```
[Inspiration] → [FacetBox] → [RelationBox] → [Inspiration] → …
```

- 图节点：`Inspiration`、最外层 `FacetBox`、最外层 `RelationBox`。
- 边：`Inspiration → FacetBox → RelationBox → Inspiration`。
- 允许分支 / 合并。
- `FacetBox` / `RelationBox` 内部是树，不参与图连接。
- 输出框不在链上，挂在图旁边，引用一组节点 / 路径。

## 关键约束

- 一条链的两端必须是 `Inspiration`。
- 只有 `depth = 0` 的框能出现在 `Connection` 里。
- 数据层不限制嵌套层数 / 跳数；UI 默认折叠。
- 灵感发送到画布是复制；`StickyNote` 保留 `sourceInspirationId` 仅用于溯源，不同步。
- 输出框手动创建；保存后生成 `Document`。

## 待确认

- `OutputBox.contextNodeIds` 应该表示节点集合、一条路径，还是一个子图。
- 一个 `OutputBox` 能否生成多个 `Document`。
- `GenerationHistory` 保存多久、是否支持逐层回溯。
