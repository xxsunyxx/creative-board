# 概念数据模型（草案 v0.2）

> 本版按「连接线 + 线上的维度框」和「灵感 / 输出两类节点」重写。
> 只描述对象和关系，不涉及技术选型。

## 节点

### CanvasNode（基类）

- `id`
- `canvasId`
- `type`：inspiration / output
- `position`（x, y）
- `size`（可空）

### InspirationNode（灵感节点）

- `id`
- `canvasId`
- `sourceInspirationId`（复制来源，仅用于溯源，不同步）
- `title`
- `content`
- `keywords[]`

### OutputNode（输出节点）

- `id`
- `canvasId`
- `contextConnectionIds[]`（这轮输出引用的连接）
- `contextNodeIds[]`（这轮输出引用的灵感节点）
- `questions[]`（AI 候选问题）
- `selectedQuestion`
- `result`（AI 生成的结果 / 预览）
- `documentId`（保存后关联）
- `status`：draft / saved

## 边

### Connection（连接线）

- `id`
- `canvasId`
- `fromNodeId`
- `toNodeId`
- `dimensionGroups[]`
- 允许分支 / 合并：节点可以有多条入线 / 出线。

### DimensionGroup（维度框）

- `id`
- `connectionId`
- `relationType`：约束 / 因果 / 类比 / 条件 / 转化……
- `mainDimensions[]`（主维度树）
- `selectedDimensionId`
- `attributes`（强度、证据、时间尺度……）
- `order`（同一条线上的多个框如何排列）

### DimensionNode（主维度 / 细节维度）

- `id`
- `groupId`
- `parentId`（可空）
- `label`
- `level`：main / detail / deeper
- `children[]`
- `selected`（是否被选中）

> `DimensionNode` 是一棵树，不是图节点；它只属于某条 `Connection`。

## 文档

### Document

- `id`
- `outputNodeId`
- `title`
- `content`
- `createdAt` / `updatedAt`

## 生成历史

### GenerationHistory

- `id`
- `targetType`：dimensionGroup / dimensionNode / question / result
- `targetId`
- `candidates[]`
- `selected`
- `createdAt`

## 图结构

```
[InspirationNode] ── Connection ── [InspirationNode]
                         │
                  DimensionGroup
                         │
                  DimensionNode (树)
```

- 图节点：`InspirationNode`、`OutputNode`。
- 边：`Connection`。
- 维度框是边上的属性 / 注释，不参与图连接。
- 多层：
  - 一条 `Connection` 可以有多个 `DimensionGroup`。
  - 每个 `DimensionGroup` 内可以有任意深度的 `DimensionNode` 树。
  - 跨灵感多跳 = 多条 `Connection` 串成路径。
- 分支 / 合并 = 节点有多条入线 / 出线。

## 关键约束

- 灵感发送到画布是复制；`sourceInspirationId` 仅用于溯源，不同步。
- 维度框不改变连通性；只有 `Connection` 决定节点之间是否相连。
- 数据层不限制维度框数量 / 细节深度 / 跳数；UI 折叠。
- 输出节点手动创建；保存后生成 `Document`。
