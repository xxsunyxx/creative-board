# 概念数据模型（草案 v0.2）

> 本版按「连接线 + 线上的维度框」和「灵感 / 输出两类节点」重写。
> 只描述对象和关系，不涉及技术选型。

## 灵感库

### Inspiration（灵感库条目）

- `id`
- `title`
- `content`
- `sourceUrl`（可空）
- `keywords[]`
- `mergedFrom[]`
- `status`：active / merged / archived
- `notes[]`（从画布便签同步回来的备注，追加式；每条是一段 `InspirationNote`）
- `createdAt` / `updatedAt`

> 备注以追加记录保存，展示时按时间追加到灵感文字里；每次修改都会新增一段，保留历史。

### InspirationNote（备注段）

- `id`
- `inspirationId`
- `stickyNoteId`
- `content`
- `createdAt`

## 画布

### Canvas

- `id`
- `name`
- `description`
- `colorLegend[]`（颜色分组：颜色 + 标签）
- `createdAt` / `updatedAt`

### ColorGroup（颜色分组）

- `color`
- `label`（AI 自动生成，可编辑）
- `autoGenerated`（是否由 AI 生成）

## 画布节点

### CanvasNode（基类）

- `id`
- `canvasId`
- `type`：inspiration / output
- `position`（x, y）
- `size`（可空）

### InspirationNode（灵感节点）

- `id`
- `canvasId`
- `sourceInspirationId`（复制来源，仅用于溯源，不同步）
- `title`
- `content`
- `keywords[]`
- `weight`（1-9，表示重要性，参与 AI 排序）
- `color`（分组标记）
- `note`（便签备注，自动追加到灵感库条目的 `notes[]`）
- `deletedAt`（可空）

### OutputNode（输出节点）

- `id`
- `canvasId`
- `contextConnectionIds[]`（这轮输出引用的连接）
- `contextNodeIds[]`（这轮输出引用的灵感节点）
- `questions[]`（AI 候选问题）
- `selectedQuestion`
- `result`（AI 生成的结果 / 预览）
- `documentIds[]`（保存后关联，可多篇）
- `status`：draft / saved

## 边

### Connection（连接线）

- `id`
- `canvasId`
- `fromNodeId`（InspirationNode 或 OutputNode）
- `toNodeId`（InspirationNode 或 OutputNode）
- `dimensionGroups[]`
- 允许分支 / 合并：节点可以有多条入线 / 出线。

### ProvenanceLink（来源虚线）

- `id`
- `outputNodeId`
- `contextNodeIds[]`
- `contextConnectionIds[]`
- 只表示「输出节点来自哪组灵感 / 连接」，不参与维度框和图连接。

### DimensionGroup（维度框）

- `id`
- `connectionId`
- `relationType`：约束 / 因果 / 类比 / 条件 / 转化……
- `mainDimensions[]`（主维度树）
- `selectedDimensionId`
- `attributes`（强度、证据、时间尺度……）
- `order`（同一条线上的多个框如何排列）

### DimensionNode（主维度 / 细节维度）

- `id`
- `groupId`
- `parentId`（可空）
- `label`
- `level`：main / detail / deeper
- `children[]`
- `selected`（是否被选中）

> `DimensionNode` 是一棵树，不是图节点；它只属于某条 `Connection`。

## 文档

### Document

- `id`
- `outputNodeId`
- `title`
- `content`
- `createdAt` / `updatedAt`

> 一个 `OutputNode` 可以对应多个 `Document`；每篇文档保存时记录自己的内容快照。

## 生成历史

### GenerationHistory

- `id`
- `targetType`：dimensionGroup / dimensionNode / question / result
- `targetId`
- `candidates[]`
- `selected`
- `createdAt`

## 图结构

```
[InspirationNode] ── Connection ── [InspirationNode / OutputNode]
                         │
                  DimensionGroup
                         │
                  DimensionNode (树)

[OutputNode] ┄┄ ProvenanceLink ┄┄ [上下文灵感 / 连接]
```

- 图节点：`InspirationNode`、`OutputNode`。
- 边：`Connection`；两端可以是灵感节点或输出节点。
- 维度框是边上的属性 / 注释，不参与图连接。
- 多层：
  - 一条 `Connection` 可以有多个 `DimensionGroup`。
  - 每个 `DimensionGroup` 内可以有任意深度的 `DimensionNode` 树。
  - 跨灵感多跳 = 多条 `Connection` 串成路径。
- 分支 / 合并 = 节点有多条入线 / 出线。
- `OutputNode` 通过虚线 `ProvenanceLink` 关联它总结的灵感组 / 连接。

## 关键约束

- 灵感发送到画布是复制；正文、关键词等不同步；便签备注会自动追加到灵感库条目的 `notes[]`。
- 备注是追加式：每次修改新增一条 `InspirationNote`；UI 需要按时间分组或折叠历史。
- 删除便签只软删除 `InspirationNode` 和它的 `Connection`；`Inspiration` 保留。
- 权重参与 AI 排序；视觉上用边框 / 角标表示，不改变便签大小。
- 颜色是分组标记；`Canvas.colorLegend` 保存颜色与 AI 自动标签。
- 维度框不改变连通性；只有 `Connection` 决定节点之间是否相连。
- 数据层不限制维度框数量 / 细节深度 / 跳数；UI 折叠。
- 输出节点手动创建；可以继续连接；保存后可生成多篇 `Document`。
