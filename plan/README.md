# 创意画板 · 项目计划

> 状态：**机制对齐中**。连接线与维度框的关系待确认，仍不写代码。

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感区收集和融合素材，画布区用便利贴和 AI 生成的特质框建立关系，收敛区沉淀问题与结果。

- 初步倾向 Web + 后台，但**尚未锁定**。

## 当前方向（2026-10-23）

- **形态**：灵感库 + 多个画布 + 文档。不是固定三栏。
- **核心机制**：灵感条目 →（融合生成新灵感）→ 复制到画布 → 灵感节点 → 连接线 + 维度框 → 多层连接 → 手动创建输出节点 → 结果预览 → 保存到文档区。
- **连接规则**：连接线是主对象；维度框是线上的注释；一条线可以有多个维度框；框内是「关系类型 → 主维度 → 细节维度」的树；允许分支 / 合并；数据不限层，UI 折叠。
- **输出规则**：输出节点在画布上；结果在输出节点里；文档在文档区。三层分开。
- **便签属性**：权重 1-9（重要性，参与 AI 排序）、颜色（分组标记 + AI 标签）、备注（每次修改追加新段）、删除（只删便签和连线，保留灵感库条目）。
- **范围选择**：多画布扁平列表；融合保留原文并标记；预览可编辑 + 重生成；AI 生成灵感手动触发。
- **场景**：学习 / 研究整理，以及一般的创意发散。
- **AI 角色**：提取关键词、辅助融合、生成主维度与细节维度、生成候选问题、生成结果预览与文档。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **颜色标签**：什么时候生成，换色时自动生成还是手动触发
2. **备注历史**：按时间分组、折叠，还是只显示最近几条
3. **权重视觉**：边框 / 角标的具体样式
4. **关系类型清单**：首版放哪些类型
5. **多个维度框的避让**：沿线平铺时连线怎么弯曲 / 避让
6. **一个输出节点多篇文档**：如何命名 / 区分
7. **输出节点尺寸**：拉伸 / 滚动的上限
8. **AI 生成灵感**：是否自动进入灵感库
9. **首版 MVP 砍到哪一步**
10. **资料导入深度、引用溯源、后台与技术选型**
