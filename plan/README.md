## 当前方向（2026-10-23）

- **形态**：以无限画布为载体的 AI 研究 / 思考工具；保留灵感墙「摊开素材」的体验，核心是 AI 辅助收敛。
- **场景**：学习 / 研究整理，从发散的材料收敛出一篇结构化笔记 / 摘要。
- **输入**：网页 / 文章摘录、PDF / 论文、自己的笔记、表格 / 数据、链接 / 引用。
- **AI 角色**：选中画布元素，用自然语言指令**理清结构 + 生成新内容**。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面、手机、平板都希望覆盖；首版建议桌面优先，待定。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

2. **AI 修改的控制方式**：先提案、直接改可撤销，还是侧边建议
3. **第一版主设备与跨端分工**：三端同权会显著放大范围
4. **资料导入深度**：全文解析，还是先链接 + 摘录
5. **引用 / 溯源的粒度**：卡片级、段落级，还是原文高亮
6. **后台职责**：账号、存储、解析、AI 代理、检索
7. **AI 实时协作的具体形态**：流式生成、局部预览、撤销
8. **公开程度与商业化**：先不急着定
