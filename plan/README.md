## 当前方向（2026-10-23）

- **形态**：灵感墙 + AI 共创画板的结合，强调「和 AI 实时协作」。
- **首版用户**：自己和朋友 / 小圈子。

## 待定（按重要性）

1. **具体场景与产出**：什么时候打开、解决什么问题、最后留下什么
2. **AI 的角色**：生成素材、主动建议、按指令修改，还是像协作者一样在画布上操作
3. **朋友 / 小圈子的参与方式**：只看、评论、共同编辑，还是各做各的
4. **第一版主设备与跨端分工**：三端同权会显著放大范围
5. **后台的职责**：账号、云存储、分享、协作、AI 代理、素材库……
6. **实时协作程度**：AI 实时 vs 多人实时，是否首版必须
7. **公开程度与商业化**：先不急着定
