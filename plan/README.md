# 创意画板 · 项目计划

> 状态：**方向收敛中**。灵感库 / 画布 / 文档的结构已浮现，仍不写代码。
> 开始：2026-10-23 ｜ 最后更新：2026-10-23

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感区收集和融合素材，画布区用便利贴和 AI 生成的特质框建立关系，收敛区沉淀问题与结果。

## 已确认

- 先讨论清楚再动手，讨论收敛前不写实现代码。
- 讨论过程和结论都放在本目录。
- **项目范围仅限当前 `creative-board` 目录**；不查阅、不引用其他目录的内容。
- 初步倾向 Web + 后台，但**尚未锁定**。

## 当前方向（2026-10-23）

- **形态**：灵感库 + 多个画布 + 文档。不是固定三栏。
- **核心机制**：灵感条目 →（融合生成新灵感）→ 发送到画布 → 便利贴 → AI 特质框 → 连接 → 画布上的输出框 → 对应文档。
- **场景**：学习 / 研究整理，以及一般的创意发散。
- **AI 角色**：提取关键词、辅助融合、生成连接特质、生成候选问题、生成文档。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **特质框的统一模型**：侧面 + 关系 + 属性，是否确认
2. **「发送到画布」的语义**：复制一份，还是引用同一个灵感
3. **多个画布如何组织**：按项目、主题，还是自由创建
4. **输出框的粒度**：每条连接一个，还是每组连接一个
5. **文档放在哪里**：独立文档区、画布侧边，还是新页面
6. **灵感融合后的原文去留**
7. **首版 MVP 砍到哪一步**
8. **资料导入深度、引用溯源、后台与技术选型**
