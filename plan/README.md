# 创意画板 · 项目计划

> 状态：**方向收敛中**。三区结构和核心机制已浮现，仍不写代码。
> 开始：2026-10-23 ｜ 最后更新：2026-10-23

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感区收集和融合素材，画布区用便利贴和 AI 生成的特质框建立关系，收敛区沉淀问题与结果。

## 已确认

- 先讨论清楚再动手，讨论收敛前不写实现代码。
- 讨论过程和结论都放在本目录。
- **项目范围仅限当前 `creative-board` 目录**；不查阅、不引用其他目录的内容。
- 初步倾向 Web + 后台，但**尚未锁定**。

## 当前方向（2026-10-23）

- **形态**：三区工作台——灵感（收集）、画布（连接）、收敛（结果）。
- **核心机制**：灵感条目 → 便利贴 → AI 生成特质框 → 连接 → 输出框 → 收敛。
- **场景**：学习 / 研究整理，以及一般的创意发散。
- **AI 角色**：提取关键词、辅助融合、生成连接特质、生成候选问题、生成结果。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **特质框的语义**：灵感 A 的侧面，还是 A 与 B 之间的关系
2. **输出框的粒度**：每条连接、每组连接，还是整个画布一个
3. **灵感融合后的原文去留**：保留、替换，还是生成新条目
4. **三区布局**：同屏三栏，还是可切换的工作区
5. **首版 MVP 砍到哪一步**
6. **资料导入深度与引用 / 溯源粒度**
7. **后台职责与技术选型**
8. **跨端适配与多人 / 公开 / 商业化**：首版之后再说
