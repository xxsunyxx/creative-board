# 创意画板 · 项目计划

> 状态：**机制对齐中**。连接线与维度框的关系待确认，仍不写代码。

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感区收集和融合素材，画布区用便利贴和 AI 生成的特质框建立关系，收敛区沉淀问题与结果。

- 讨论过程和结论都放在本目录。
- **项目范围仅限当前 `creative-board` 目录**；不查阅、不引用其他目录的内容。
- 初步倾向 Web + 后台，但**尚未锁定**。

## 当前方向（2026-10-23）

- **形态**：灵感库 + 多个画布 + 文档。不是固定三栏。
- **核心机制**：灵感条目 →（融合生成新灵感）→ 复制到画布 → 便利贴 → 侧面框 → 关系框 → **多层连接** → 手动创建输出框 → 预览 → 保存到文档区。
- **连接规则**：允许分支 / 合并；两端都是灵感；只有最外层框能外连；数据不限层，UI 折叠。
- **场景**：学习 / 研究整理，以及一般的创意发散。
- **AI 角色**：提取关键词、辅助融合、生成侧面与关系候选、生成候选问题、生成预览与文档。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **连接线与维度框的关系**：维度框是线上的注释，还是可连接的节点
2. **结果 / 输出 / 文档的区分**：输出是否作为画布上的一等节点
3. **完整链的形态**：是否固定为「灵感 → 侧面 → 关系 → 灵感」，是否保留快速连接
4. **分支 / 合并的显示**：如何避免画布变成蜘蛛网
5. **嵌套是否允许交叉**：侧面套关系，还是只做同类嵌套
6. **输出框的上下文**：整条链、选中的一段，还是整个画布
7. **输出框的创建方式**：先选中连接再生成，还是先放空框再拖入
8. **输出框与文档的关系**：一对一，还是一对多
9. **多个画布如何组织**：按项目、主题，还是自由创建
10. **灵感融合后的原文去留**
11. **预览结果能否编辑、重新生成、部分采纳**
12. **首版 MVP 砍到哪一步**
13. **资料导入深度、引用溯源、后台与技术选型**
