# 创意画板 · 项目计划

> 状态：**方向收敛中**。灵感库 / 画布 / 文档的结构已浮现，仍不写代码。

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感区收集和融合素材，画布区用便利贴和 AI 生成的特质框建立关系，收敛区沉淀问题与结果。

## 已确认

- 先讨论清楚再动手，讨论收敛前不写实现代码。
- 讨论过程和结论都放在本目录。
- **项目范围仅限当前 `creative-board` 目录**；不查阅、不引用其他目录的内容。
- 初步倾向 Web + 后台，但**尚未锁定**。

## 当前方向（2026-10-23）

- **形态**：灵感库 + 多个画布 + 文档。不是固定三栏。
- **核心机制**：灵感条目 →（融合生成新灵感）→ 复制到画布 → 便利贴 → 侧面框 → 关系框 → 手动创建输出框 → 预览 → 保存到文档区。
- **场景**：学习 / 研究整理，以及一般的创意发散。
- **AI 角色**：提取关键词、辅助融合、生成侧面与关系候选、生成候选问题、生成预览与文档。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **侧面框与关系框的连接顺序**：是否固定为 A → 侧面框 → 关系框 → B，是否每次都必须两个框
2. **输出框的创建方式**：先选中连接再生成，还是先放空框再拖入
3. **输出框与文档的关系**：一对一，还是一对多
4. **多个画布如何组织**：按项目、主题，还是自由创建
5. **灵感融合后的原文去留**
6. **预览结果能否编辑、重新生成、部分采纳**
7. **首版 MVP 砍到哪一步**
8. **资料导入深度、引用溯源、后台与技术选型**
