## 当前方向（2026-10-23）

- **形态**：灵感墙 + AI 共创画板的结合，强调「和 AI 实时协作」。
- **场景**：学习 / 研究整理，从发散的材料收敛出一个结果。
- **AI 角色**：选中画布元素，用自然语言指令修改、重排、延展。
- **首版用户**：自己和朋友 / 小圈子。
- **分享**：希望支持 private、多人共创、只读 public；首版优先级待定。
- **设备**：桌面、手机、平板都希望覆盖；主次待定。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **收敛结果的具体形态**：结构化笔记、概念图、提纲、结论，还是可讲的展示
2. **画板上的资料类型与导入方式**：网页、PDF、图片、笔记、音视频……
3. **AI 修改的重点**：改文字、理结构、生成内容，还是调布局
4. **分享模式的首版优先级**：私有、只读公开、邀请共创
5. **第一版主设备与跨端分工**：三端同权会显著放大范围
6. **后台的职责**：账号、云存储、分享、协作、AI 代理、素材库……
7. **实时协作程度**：AI 实时 vs 多人实时，是否首版必须
8. **公开程度与商业化**：先不急着定
