## 当前方向（2026-10-23）

- **形态**：画布 + 独立文档区。画布是思考的中间态，文档区承载最终的结构化笔记。
- **场景**：学习 / 研究整理，从发散的材料收敛出一篇结构化笔记 / 摘要。
- **输入**：网页 / 文章摘录、PDF / 论文、自己的笔记、表格 / 数据、链接 / 引用。
- **AI 角色**：选中画布元素，用自然语言指令**理清结构 + 生成新内容**；具体交互方式待用户描述。
- **首版用户**：自己。
- **分享**：首版默认私有；之后再考虑共创、只读公开。
- **设备**：桌面为主；手机 / 平板后续适配。
- **首版目标**：验证自己愿不愿意持续使用。

## 待定（按重要性）

1. **AI 修改的具体交互**：用户对现有选项不满意，待直接描述
2. **画布到文档的过渡**：手动整理、一键生成，还是双向关联
3. **资料导入深度**：全文解析，还是先链接 + 摘录
4. **引用 / 溯源的粒度**：卡片级、段落级，还是原文高亮
5. **后台职责**：账号、存储、解析、AI 代理、检索
6. **跨端适配范围**：桌面之后，手机 / 平板先做哪一端
7. **多人 / 公开 / 商业化**：首版之后再说
