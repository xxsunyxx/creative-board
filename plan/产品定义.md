# 产品定义（草稿 v0.5）

> 状态：讨论中，不是最终需求；随时可能改。
> 更新：2026-10-23

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感库收集和融合素材，灵感可以复制到多个画布，用侧面框和关系框建立连接，手动创建输出框，预览结果后保存为文档。

## 用户

- 首版：自己（验证是否愿意持续使用）。
- 之后：朋友 / 小圈子；支持私有、共创、只读公开。

## 问题

学习、研究或做创意时，资料和想法散落在浏览器、PDF、笔记和脑子里。收集不是最难的，难的是：

- 素材之间没有关系，看完就散；
- 想法很多，但不知道从哪个方向连起来；
- 连接只靠一条线，说不清「为什么连」「连的是哪一面」；
- 最后产出的结论和过程脱节，无法回溯。

## 产品结构

- **灵感库**：收集链接、文字、笔记；支持融合、补充、文字整理；生成可编辑的关键词。融合后生成新的灵感条目，继续留在灵感库。
- **画布（可多个）**：灵感复制到画布变成便利贴；通过侧面框和关系框建立**多层连接**（框内嵌套、链式连接、跨灵感多跳）；两个灵感可以连接到第三个灵感；输出框手动创建。
- **文档**：输出框先给预览结果，确认保存后写入文档区。

## 核心闭环

1. **收集**：把链接、文字、笔记放进灵感库，形成一条条灵感。
2. **融合**：把相关灵感拖到一起，生成一条新的灵感条目；原文是否保留待定。
3. **上画布**：选择一条灵感，点击「发送到画布」，复制到目标画布。
4. **连接**：点击连接区，AI 生成侧面；选侧面生成侧面框；再生成关系框；连到另一个灵感；连接可以继续多层展开。
5. **输出**：手动在画布上创建输出框，AI 给出候选问题。
6. **成稿**：选择问题，生成预览结果；确认后保存，写入文档区。

## 连接规则（已确认）

- 链式连接允许分支和合并。
- 一条链的两端都是灵感；输出框不作为链的端点。
- 框内嵌套的子级不能向外连接，只有最外层框能连。
- 数据层不限制层数 / 跳数；UI 默认折叠，按需展开。

## AI 的角色

- 提取和补充关键词。
- 判断灵感之间的相关性，辅助融合与文字整理。
- 生成侧面候选和关系候选，支持刷新和回溯。
- 基于连接生成候选问题。
- 生成预览结果和文档内容。

## 首版边界（暂定）

- 私有，单人使用。
- 桌面为主；手机 / 平板后续适配。
- 输入：链接、文字、自己的笔记；PDF / 表格可以后置。
- 至少包含：灵感库、一个画布、侧面框、关系框、**多层连接**、输出框、文档区。
- 连接必须支持多层，不砍成一层。
- 不做：自由绘画、复杂图形设计、音视频解析、公开社区、多人实时编辑。

## 关键风险

1. **多层连接的可读性**：层数一多，画布容易变成蜘蛛网；需要折叠、聚焦、分层显示。
2. **两种框的复杂度**：侧面框 + 关系框比一条线重得多，第一次用可能觉得绕。
3. **手动输出框的时机**：用户可能不知道什么时候该输出，或者忘了输出。
4. **预览质量**：如果预览结果空洞，保存到文档区只会制造更多垃圾。
5. **导航复杂度**：灵感库、多个画布、文档三个空间，如果没有清晰层级，用户会迷路。
6. **范围膨胀**：灵感库 + 多画布 + 多层连接 + 输出框 + 文档 + AI，任何一项都能吃掉首版。

## 待确认

- 一条完整链是否固定为「灵感 → 侧面 → 关系 → 灵感」，还是允许连续多个侧面 / 关系？
- 是否保留「快速连接」：不选侧面 / 关系，直接连两个灵感？
- 分支 / 合并在画布上如何显示，避免变成蜘蛛网？
- 框内嵌套是只做同类嵌套，还是侧面和关系可以交叉嵌套？
- 侧面框和关系框的连接顺序是否固定？是否每次都必须两个框？
- 侧面框 / 关系框能否复用到多条连接？
- 输出框如何创建：先选中连接再生成，还是先放空框再拖入？
- 输出框的上下文如何选：整条链、选中的一段，还是整个画布？
- 一个输出框能保存多篇文档吗？
- 预览结果可以编辑、重新生成、只采纳一部分吗？
- 多个画布如何组织：按项目、主题，还是自由创建？
- 灵感融合后，原文是否保留？
- 首版 MVP 砍到哪一步。
- 资料导入深度、引用溯源、后台职责与技术选型。
