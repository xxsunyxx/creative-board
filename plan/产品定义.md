# 产品定义（草稿 v0.1）

> 状态：讨论中，不是最终需求；随时可能改。
> 更新：2026-10-23

## 一句话

一个私有的 AI 研究画布：把网页摘录、PDF、笔记、表格和链接摊在画布上，选中一块，用自然语言让 AI 理结构、生成内容，最后收敛成一篇结构化笔记。

## 用户

- 首版：自己（验证是否愿意持续使用）。
- 之后：朋友 / 小圈子；支持私有、共创、只读公开。

## 问题

学习 / 研究时，资料散落在浏览器、PDF、笔记和表格里。收集不是最难的，难的是：

- 看完记不住，素材之间没有关系；
- 资料越多，越难判断什么重要；
- 知道要写什么，但整理不出结构；
- 最后产出的笔记和原始资料脱节，无法回溯。

## 核心闭环（假设）

1. **收集**：把网页摘录、PDF、笔记、表格、链接放进画布。
2. **摊开**：以卡片 / 分区的方式摆放，建立初步的空间关系。
3. **指令**：选中一张或一组卡片，用自然语言让 AI 归类、命名、补全、生成摘要。
4. **收敛**：把整理结果沉淀成一篇结构化笔记。
5. **回看**：笔记与素材保持引用关系，能点回原文。

## AI 的角色

- 不是侧边栏聊天机器人，而是画布上的编辑者。
- 核心动作：**理清结构** + **生成新内容**。
- 交互假设：选中元素 → 自然语言指令 → 预览 / 执行 → 可撤销。
- 首版不做：AI 主动打扰、自动改全画布、多人实时协作。

## 首版边界（暂定）

- 私有，单人使用。
- 桌面优先；手机 / 平板先满足查看或轻量收集。
- 输入：网页 / 文章摘录、PDF / 论文、自己的笔记、表格 / 数据、链接 / 引用。
- 输出：结构化笔记 / 摘要。
- 不做：自由绘画、复杂图形设计、音视频解析、公开社区、多人实时编辑。

## 关键风险

1. **画布的必要性**：如果只是「素材 + AI 摘要」，文档工具也能做；画布必须提供空间化思考和关系发现的价值。
2. **AI 的可控性**：结构修改如果不可预期，用户会不敢用；预览、撤销、局部执行很重要。
3. **资料解析质量**：PDF / 网页的解析和引用溯源决定信任度。
4. **范围膨胀**：三端 + 多人 + AI + 解析，任何一项都能吃掉首版。

## 待确认

- 画布与最终笔记的关系。
- AI 结构修改的控制方式。
- 首版主设备。
- 资料导入深度：全文解析，还是先链接 + 摘录？
- 引用 / 溯源的粒度。
- 后台职责与技术选型。
