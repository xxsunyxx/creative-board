# 产品定义（草稿 v0.4）

> 状态：讨论中，不是最终需求；随时可能改。
> 更新：2026-10-23

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感库存放和融合素材，灵感可以发送到多个画布，在画布上用便利贴和 AI 特质框建立关系，输出框在画布上生成对应文档。

## 用户

- 首版：自己（验证是否愿意持续使用）。
- 之后：朋友 / 小圈子；支持私有、共创、只读公开。

## 问题

学习、研究或做创意时，资料和想法散落在浏览器、PDF、笔记和脑子里。收集不是最难的，难的是：

- 素材之间没有关系，看完就散；
- 想法很多，但不知道从哪个方向连起来；
- 连接只靠一条线，说不清「为什么连」「连的是哪一面」；
- 最后产出的结论和过程脱节，无法回溯。

## 产品结构

- **灵感库**：收集链接、文字、笔记；支持融合、补充、文字整理；生成可编辑的关键词。融合后生成新的灵感条目，继续留在灵感库。
- **画布（可多个）**：灵感通过「发送到画布」变成便利贴；通过连接区和 AI 生成的特质框建立关系；支持多层级特质和两个灵感连接第三个灵感。
- **文档**：画布上的输出框生成对应文档，作为这一轮思考的成稿。

## 核心闭环

1. **收集**：把链接、文字、笔记放进灵感库，形成一条条灵感。
2. **融合**：把相关灵感拖到一起，生成一条新的灵感条目；原文是否保留待定。
3. **上画布**：选择一条灵感，点击「发送到画布」，选择目标画布。
4. **连接**：点击连接区，AI 生成连接方向 / 特质；选择后生成特质框，再连到另一个灵感。
5. **输出**：连接后，画布上出现输出框，AI 给出候选问题。
6. **成稿**：选择问题，AI 生成对应文档；输出框保留在画布上作为流程依据。

## AI 的角色

- 提取和补充关键词。
- 判断灵感之间的相关性，辅助融合与文字整理。
- 生成连接特质，支持刷新和回溯。
- 基于连接生成候选问题。
- 生成对应文档。

## 首版边界（暂定）

- 私有，单人使用。
- 桌面为主；手机 / 平板后续适配。
- 输入：链接、文字、自己的笔记；PDF / 表格可以后置。
- 至少包含：灵感库、一个画布、连接区 / 特质框、输出框、文档。
- 不做：自由绘画、复杂图形设计、音视频解析、公开社区、多人实时编辑。

## 关键风险

1. **导航复杂度**：灵感库、多个画布、文档三个空间，如果没有清晰的层级，用户会迷路。
2. **画布上的输出框**：显眼是优点，但太多会遮挡画布；需要控制出现时机和数量。
3. **特质框的理解成本**：概念很强，但第一次用可能不懂「为什么先生成特质再连接」。
4. **AI 生成质量**：特质、问题、文档任何一环空洞，整个闭环就不可信。
5. **范围膨胀**：灵感库 + 多画布 + 图结构 + 文档 + AI，任何一项都能吃掉首版。

## 待确认

- 特质框的统一模型（侧面 + 关系 + 属性）是否确认？
- 「发送到画布」是复制还是引用？画布上的修改是否回写灵感库？
- 多个画布如何组织：按项目、主题，还是自由创建？
- 输出框的粒度：每条连接一个，还是每组连接一个？
- 文档放在哪里：独立文档区、画布侧边，还是新页面？
- 灵感融合后，原文是否保留？
- 首版 MVP 砍到哪一步。
- 资料导入深度、引用溯源、后台职责与技术选型。
