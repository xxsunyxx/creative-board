# 产品定义（草稿 v0.6）

> 状态：讨论中，不是最终需求；随时可能改。
> 更新：2026-10-23

## 一句话

一个私有的 AI 创意 / 研究工作台：灵感库收集和融合素材，灵感复制到多个画布；画布上用连接线和线上的维度框建立多层关系，手动创建输出节点，结果预览后保存为文档。

## 用户

- 首版：自己（验证是否愿意持续使用）。
- 之后：朋友 / 小圈子；支持私有、共创、只读公开。

## 问题

学习、研究或做创意时，资料和想法散落在浏览器、PDF、笔记和脑子里。收集不是最难的，难的是：

- 素材之间没有关系，看完就散；
- 想法很多，但不知道从哪个方向连起来；
- 连接只靠一条线，说不清「为什么连」「连的是哪一面」；
- 最后产出的结论和过程脱节，无法回溯。

## 产品结构

- **灵感库**：收集链接、文字、笔记；支持融合、补充、文字整理；生成可编辑的关键词。融合后生成新的灵感条目，继续留在灵感库。
- **画布（可多个）**：两类节点——灵感节点、输出节点；节点之间用连接线相连；连接线上挂维度框。灵感便签支持权重（1-9）、颜色、备注（可同步到灵感文字）和删除。
- **文档**：输出节点先给结果预览，确认保存后写入文档区。

## 核心闭环

1. **收集**：把链接、文字、笔记放进灵感库，形成一条条灵感。
2. **融合**：把相关灵感拖到一起，生成一条新的灵感条目；原文是否保留待定。
3. **上画布**：选择一条灵感，点击「发送到画布」，复制到目标画布。
4. **连接**：从灵感 A 拉线到灵感 B；线上添加维度框（关系类型 → 主维度 → 细节维度）；可以继续加框、继续多跳。
5. **输出**：选中一条链或一组连接，手动创建输出节点；AI 给出候选问题。
6. **成稿**：选择问题，生成结果预览；确认后保存，写入文档区。

## 便签属性（已确认）

- **权重**：1-9 的数字输入，表示重要性，参与 AI 生成时的优先级排序；视觉上用边框 / 角标表示，不改变大小。
- **颜色**：可更换，作为分组标记；每种颜色有一个 AI 自动生成的标签，可编辑。
- **备注**：便签上的独立备注，自动追加到灵感文字里；每次修改追加一个新段，保留历史。
- **删除**：只删除画布便签及其连线，灵感库条目保留。
- 便签的权重、颜色、备注、删除都在便签上直接操作，不依赖侧栏。

## 连接规则（已确认）

- **连接线是主对象**；先连线，再在线上加维度框。
- **连接的两端可以是灵感节点，也可以是输出节点**；输出节点可以继续连接，作为下一轮输入。
- **维度框是线上的注释**，不是图节点；不参与其他连接。
- 一条线可以有多个维度框，例如「约束」「因果」「类比」同时挂在同一条线上；多个框沿连接线平铺。
- 每个维度框内部是一棵树：**关系类型 → 主维度 → 细节维度 → 更深细节**。
- 主维度 / 细节维度可由 AI 生成，也可以手动增删改。
- **多层** = 多个维度框 + 框内细节树 + 跨灵感多跳。
- 分支 / 合并允许：节点可以有多条入线 / 出线。
- 维度框不改变图的连通性；它只描述这条线「从哪个方向连」。
- 数据层不限制维度框数量 / 细节深度 / 跳数；UI 默认折叠。
- 连好线后，关系类型选择器给出 **AI 推荐 + 固定清单**，由用户选第一个维度框。

## 输出规则（已确认）

- **输出**：画布上的输出节点。
- **结果**：输出节点里的 AI 生成内容（预览 / 最终），在节点内展开。
- **文档**：保存后的成稿，放在文档区。
- 输出节点手动创建；创建时以选中的一组灵感 / 连接为上下文。
- 输出节点和它总结的灵感组之间画一条**虚线**。
- 输出节点可以继续连接到其他灵感 / 输出；连接时也走「关系类型 → 主维度 → 细节」。
- 一个输出节点可以保存**多篇文档**，每篇独立生成。
- 保存后文档区出现文档；输出节点保留，作为入口。

## AI 的角色

- 提取和补充关键词。
- 判断灵感之间的相关性，辅助融合与文字整理。
- 生成维度框的主维度和细节维度，支持刷新和回溯。
- 生成候选问题。
- 生成结果预览和文档内容。

## 首版边界（暂定）

- 私有，单人使用。
- 桌面为主；手机 / 平板后续适配。
- 输入：链接、文字、自己的笔记；PDF / 表格可以后置。
- 至少包含：灵感库、多个画布（扁平列表）、连接线 + 维度框、输出节点、结果预览、文档区。
- AI 生成灵感首版必须有。
- 多层连接不砍。
- 不做：自由绘画、复杂图形设计、音视频解析、公开社区、多人实时编辑。

## 关键风险

1. **线上的维度框容易拥挤**：一条线多个框、每个框又有细节树，画布会很快变乱。
2. **维度树太深**：用户可能迷失在「主维度 → 细节 → 更深细节」里。
3. **输出节点与链的关系**：输出节点是挂在链旁边，还是可以继续连接，需要明确。
4. **AI 生成质量**：主维度、细节、问题、结果任何一环空洞，整个闭环就不可信。
5. **范围膨胀**：灵感库 + 多画布 + 多层连接 + 输出节点 + 文档 + AI，任何一项都能吃掉首版。

## 待确认

- 颜色标签什么时候生成：换色时自动生成，还是用户点「生成标签」？
- 备注历史如何展示：按时间分组、折叠，还是只显示最近几条？
- 权重的边框 / 角标具体样式。
- 一条线上的多个维度框如何排列，避免遮挡？
- 一个输出节点保存多篇文档时，如何区分和命名这些文档？
- 结果预览可以编辑、重新生成、只采纳一部分吗？
- 多个画布如何组织：按项目、主题，还是自由创建？
- 灵感融合后，原文是否保留？
- 首版 MVP 砍到哪一步。
- 资料导入深度、引用溯源、后台职责与技术选型。
