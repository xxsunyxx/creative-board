# 首版范围（草案 v0.2）

## 目标

验证自己是否愿意持续使用：完整走通「灵感收集 → 融合 → 画布多层连接 → 输出节点 → 结果预览 → 文档」。

## 必须有

- **灵感库**：文字 / 链接输入、关键词、融合、发送到画布。
- **画布**：多个画布（首版扁平列表）、一种便签 + 四种角色（灵感 / 过程 / 结果 / 空白）、拖拽；便签可缩放；画布详情默认全屏；左侧栏可折叠成图标。
- **便签属性**：权重 1-9（重要性，参与 AI 排序，用边框 / 角标表示）、颜色（分组标记 + AI 自动标签）、备注（每次修改追加新段）、删除（只删便签和连线）。
- **节点角色**：AI 根据入 / 出线推断，用户可手动覆盖；结果节点可继续连接并保持结果。
- **空便签 / 碰撞**：插入空便签或空结果，摆好布局后点「开始推理」，所有空便签各生成一个候选。
- **插入过程**：在连接上拆成 A→P→B，原维度框移到 A→P；过程与维度框共存。
- **融合**：生成新灵感，原文保留并标记「已融合」。
- **AI 生成灵感**：选中两个节点后手动触发。
- **连接**：连接线 + 线上维度框；关系类型选择器 = AI 推荐 + 固定清单；一条线支持多个维度框；框内支持「主维度 → 细节维度」的树；维度可手动增删改。
- **Lucky**：关系选择器和维度面板里随机给一个关系 / 条件。
- **多层**：跨灵感多跳、分支 / 合并、数据不限层、UI 折叠。
- **AI 生成维度**：主维度、细节维度的候选与刷新 / 回溯；M4 先用 mock。
- **结果 / 文档**：结果节点、候选问题、结果预览、保存多篇独立文档（M5b）。
- **文档**：文档列表、阅读 / 编辑、跳回画布。
- **AI 设置**：OpenAI / Claude / DeepSeek；Key 只存本机 localStorage；测试后选模型保存。
- **AI 推理（E1/E2）**：逐节点 + 拓扑波次、run / patch / 撤销、本次 / 画布 tokens；真实 provider 适配已写，待真实 key 验证。
- **运行形态**：私有、桌面 Web、单用户。

## 可以后置

- PDF / 网页全文解析、剪藏插件。
- 图片 / 音视频。
- 关系类型 / 维度词汇表的完整覆盖（首版先做少量）。
- 高级可视化：路径高亮、聚焦模式、缩略图。
- 多画布项目分组。
- 多人协作、公开分享。
- 移动端。

## 不做

- 自由绘画。
- 复杂图形设计。
- 公开社区。
- 商业化。

## 待确认

- 关系类型选择器里放哪些类型，固定列表还是 AI 推荐。
- 一条线多个维度框的排列方式。
- 输出节点连接到其他节点时，是否也走维度框。
- 一个输出节点保存多篇文档的生成方式。
- 文档编辑器做到什么程度：纯文本、Markdown，还是富文本。
- 「多个画布」首版是扁平列表，还是需要项目分组。
