# 首版范围（草案 v0.1）

## 目标

验证自己是否愿意持续使用：完整走通「灵感收集 → 融合 → 画布多层连接 → 输出 → 文档」。

## 必须有

- **灵感库**：文字 / 链接输入、关键词、融合、发送到画布。
- **画布**：多个画布（先做扁平列表）、便利贴、拖拽。
- **连接**：侧面框 + 关系框、链式连接、分支 / 合并、跨灵感多跳。
- **嵌套**：数据不限层，UI 默认折叠。
- **输出**：手动输出框、候选问题、预览、保存。
- **文档**：文档列表、阅读 / 编辑、跳回画布。
- **运行形态**：私有、桌面 Web、单用户。

## 可以后置

- PDF / 网页全文解析、剪藏插件。
- 图片 / 音视频。
- AI 生成灵感（待确认是否必须）。
- 关系词汇表的完整覆盖。
- 高级可视化：路径高亮、聚焦模式、缩略图。
- 多画布项目分组。
- 多人协作、公开分享。
- 移动端。

## 不做

- 自由绘画。
- 复杂图形设计。
- 公开社区。
- 商业化。

## 待确认

- AI 生成灵感是否首版必须有？
- 灵感融合要做到什么深度：只合并文字，还是 AI 重构结构？
- 输出框如何选择上下文。
- 文档编辑器做到什么程度：纯文本、Markdown，还是富文本？
- 「多个画布」首版是扁平列表，还是需要项目分组？
