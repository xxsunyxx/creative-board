# 首版范围（草案 v0.2）

## 目标

验证自己是否愿意持续使用：完整走通「灵感收集 → 融合 → 画布多层连接 → 输出节点 → 结果预览 → 文档」。

## 必须有

- **灵感库**：文字 / 链接输入、关键词、融合、发送到画布。
- **画布**：多个画布（先做扁平列表）、灵感节点、输出节点、拖拽。
- **连接**：连接线 + 线上维度框；一条线支持多个维度框；框内支持「主维度 → 细节维度」的树。
- **多层**：跨灵感多跳、分支 / 合并、数据不限层、UI 折叠。
- **AI 生成维度**：主维度、细节维度的候选与刷新 / 回溯。
- **AI 生成灵感**：两个灵感连接时，可以生成第三个灵感。
- **输出**：手动创建输出节点、候选问题、结果预览、保存到文档。
- **文档**：文档列表、阅读 / 编辑、跳回画布。
- **运行形态**：私有、桌面 Web、单用户。

## 可以后置

- PDF / 网页全文解析、剪藏插件。
- 图片 / 音视频。
- 关系类型 / 维度词汇表的完整覆盖（首版先做少量）。
- 高级可视化：路径高亮、聚焦模式、缩略图。
- 多画布项目分组。
- 多人协作、公开分享。
- 移动端。

## 不做

- 自由绘画。
- 复杂图形设计。
- 公开社区。
- 商业化。

## 待确认

- 第一个关系类型按钮是否固定为「约束」。
- 一条线多个维度框的排列方式。
- 输出节点能否继续连接。
- 一个输出节点对应几篇文档。
- 文档编辑器做到什么程度：纯文本、Markdown，还是富文本。
- 「多个画布」首版是扁平列表，还是需要项目分组。
