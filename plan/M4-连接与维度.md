# M4 连接与维度

> 目标：把画布从「便签」推进到「可连接的思考图」。

## 已完成

### 连接

- 便签四边都有连接点，使用 React Flow loose 模式，任意边都能拉线。
- 拖动连接点 → 落点后弹出关系类型选择器。
- 选择器结构：
  - AI 推荐（mock，根据标题 / 内容关键词排序）；
  - 固定清单（因果、相关、类比、条件、约束、转化、组合、对立/张力、尺度映射）。
- 一条线支持多个维度框。
- 分支 / 合并：同一节点可以有多条入线 / 出线。
- 删除单条连接。

### 维度框

- 每个维度框包含：关系类型 → 主维度 → 细节维度 → 第三层子级。
- mock 模板已扩到每种关系 7-8 个主维度，每个 4-6 个细节；部分细节有第三层。
- 例：因果有 8 个主维度（机制、方向、时间、证据、条件、强度、主体、反事实），共 58 个节点。
- 约束有 8 个主维度（成本、资源、法规、伦理、场景、能力、利益相关者、风险），共 56 个节点。
- 支持：
  - 选维度；
  - 手动加主维度 / 子维度；
  - 删除维度框；
  - 删除整条连接；
  - 刷新 / 回溯留到接真实 AI 时补。

### 画布体验

- 便签美化：颜色渐变、顶部色条、圆角、阴影、悬浮抬升。
- 权重影响边框粗细。
- 四边随动连接点，节点拖动时跟随。
- 吸附网格：20×20。
- 自动排布：Dagre 左→右分层布局；无连接时用网格布局。
- 连接线：渐变描边 + 底描边 + 柔光 + 箭头。
- 侧栏折叠成图标，状态存 localStorage。
- 画布全屏 / 专注模式：隐藏侧栏和页面留白，画布铺满视口，保留浮动返回 / 退出按钮。

- 3 个便签正常渲染。

- 侧栏折叠成功；全屏模式成功。
- 控制台无报错，测试数据清理。
