# M0 画布技术验证

> 目的：验证 React Flow 能不能承载「一条线上多个可交互维度框」。
> 范围很小，不做完整产品。

## 要验证的事

1. 自定义灵感节点：卡片、拖拽。
2. 自定义边：一条线上渲染多个维度 chip。
3. 点击 chip：打开嵌套 popover（关系类型 → 主维度 → 细节）。
4. 节点拖拽 / 画布缩放时，chip 跟随。
5. 多个 chip 的避让 / 分布。
6. 点击 chip、popover、节点之间不冲突。
7. 画布缩放 / 平移正常。

## 不做

- 数据库、持久化。
- AI 调用。
- 灵感库、文档、输出节点。
- 登录、局域网访问。
- 最终视觉样式。

## 验收标准

- 页面显示 3-4 个灵感节点和 2-3 条连线。
- 每条线上至少 2 个维度 chip。
- 点击 chip 能打开 popover，展开主维度 / 细节并选择。
- 拖动节点，chip 位置实时跟随。
- 缩放 / 平移画布正常。
- 控制台无报错。

## 技术选择

- Next.js + React + TypeScript。
- `@xyflow/react`。
- M0 用纯 CSS，不引入 Tailwind，减少干扰。
- 数据全部 mock，放在页面内。

## 结果记录（2026-10-23）

- React Flow 12.12.0 **够用**。
- 4 个节点 / 3 条边 / 5 个 chip 正常渲染。
- 点击 chip 打开 popover；选择细节后，chip 文本实时回写。
- 拖动节点，chip 位置跟随。
- 缩放 / 平移正常。
- 点「＋ 维度框」可以动态追加 chip（5 → 6）。
- 控制台无报错。
- 已知问题：多个 chip 密集时会和节点 / 彼此重叠，需要后续做避让算法；popover 会覆盖节点，属于预期。
- 结论：**继续用 React Flow，进入 M1**。
