# M1 项目骨架

> 目标：把 Next.js、SQLite / Drizzle、工作区导航和基础写入链路跑通。

## 已完成

- Next.js App Router 工作区外壳。
- 左侧导航：灵感库 / 画布 / 文档。
- SQLite 数据库 `data/app.db`。
- Drizzle schema：12 张表（画布、灵感、关键词、备注、节点、连接、维度、文档等）。
- 种子数据：1 个画布、4 条灵感、1 篇文档。
- 灵感库页面：读取种子数据 + 表单新增灵感（Server Action）。
- 画布页面：读取画布 + 表单新建画布。
- 文档页面：列表 + Markdown 详情页。
- `/api/health`：返回画布 / 灵感 / 文档数量。
- M0 页面保留在 `/m0`。

## 命令

```bash
pnpm db:push      # 建表 / 同步本地 schema
pnpm db:seed      # 写入种子数据（已有画布时跳过）
pnpm db:generate  # 生成迁移 SQL
pnpm db:migrate   # 执行迁移
pnpm check:m1     # Playwright 冒烟测试
```
